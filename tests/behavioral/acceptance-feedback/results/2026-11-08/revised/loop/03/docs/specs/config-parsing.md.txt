# 配置解析规格

本规格接管已接受输入 `tmp/srs.md` 中的配置解析合同，作为后续维护的当前要求。原输入不承担同步维护。

## 用途与边界

本地编辑器调用 `parse_limit(value=None)` 读取用户配置。函数不执行文件或网络 I/O，不修改输入或外部状态，实现无第三方依赖。

## 已接受行为

- 缺失参数或传入 `None` 时返回整数 `30`。
- 显式值只接受 `5` 至 `120`（含）的 Python `int`；`bool` 不算 `int`。
- 其他类型和越界值抛出 `ValueError`，不隐式转换字符串或浮点数，异常不返回部分结果。

## 验收要求

覆盖 `None`、`5`、`120`、`4`、`121`、`True`、字符串 `"30"` 和浮点数 `30.0`。当前没有性能目标。未来客户建议须另行确认，不能自动成为接受要求。

## 当前实现与验收结论

已移除隐式转换并恢复精确整数类型检查；已有 3 项测试通过，结合实现核对，当前已接受合同验收通过，本次既有契约修复完成。尚无已接受性能目标或性能测量结论；`auto` 建议及体验意见仍待处理，不改变本规格。详细范围、证据和后续意见统一维护于[验收记录](../acceptance/config-parsing.md)。
