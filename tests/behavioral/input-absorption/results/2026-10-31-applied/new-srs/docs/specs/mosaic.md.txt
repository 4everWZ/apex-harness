# Mosaic 产品与技术规范

本文维护 Mosaic 已接受的整体产品契约，包括输入、特征、索引查询和验收。I01–I08、F01–F08、Q01–Q10、A01–A06 从所有者接受的需求输入承接至此；后续契约变更维护本文。契约已接受并不表示实现已交付或符合性已验证。

Mosaic 是只在本地主机运行的重复图片检索工具。调用者提供已经解码的像素矩阵；图片格式解码、网络服务及 GUI 不在范围内。特征、索引和检索仅供内部使用，没有外部 SDK、模块版本兼容发布或独立团队；工具整体发布、整体验收。

## 输入、身份和状态

- **I01**：图片必须为非空 H×W×3 整数 RGB 矩阵，各通道值在 0–255。非法维度、非整数或越界值返回 `INVALID_IMAGE`，索引状态不变。
- **I02**：H 或 W 小于 8 时返回 `IMAGE_TOO_SMALL`。不得复制像素或插值放大后接受输入。
- **I03**：每张图片具有区分大小写的 UTF-8 `image_id`。同 id、完全相同像素的重复添加返回原确认，不重建特征；同 id、不同像素返回 `ID_CONFLICT`，状态不变。
- **I04**：特征和确认仅从成功接受的原像素派生。不得自动旋转、裁剪或进行 EXIF 修正；矩阵行列顺序由调用者给出。
- **I05**：添加、删除、查询按调用顺序串行执行；本期不承诺并发写。
- **I06**：单图添加失败不得留下部分特征或 id。批添加按数组顺序逐项执行，单项失败不回滚其他成功项。
- **I07**：删除不存在的 id 为幂等成功；删除存在的 id 后不得返回其旧特征。该 id 可重新添加，按新图片处理。
- **I08**：不得修改调用者矩阵；输入返回后调用者对矩阵的修改不得改变已接受的索引内容。

## 特征定义

特征提取必须遵守下列数值与位序规则。索引内图片和查询图片使用相同规则。

- **F01**：逐像素亮度 `L=(299R+587G+114B)/1000`，不舍入为整数、不做 gamma 修正。
- **F02**：用 8×8 网格覆盖原矩阵。行 i 的范围为 `[floor(i*H/8), floor((i+1)*H/8))`，列 j 的范围为 `[floor(j*W/8), floor((j+1)*W/8))`，i、j 均为 0–7。使用区域内全部像素，不以均匀采样点替代。
- **F03**：`m[i,j]` 是相应区域全部亮度的算术平均；`mbar=(sum m[i,j])/64`，即 64 个单元等权，而非原图全部像素等权的均值。
- **F04**：`b[i,j]=1` 当且仅当 `m[i,j]>=mbar`。按行优先，位置 `(i,j)` 对应 bit `8*i+j`，从 `(0,0)` 的 bit 0 到 `(7,7)` 的 bit 63。不得按字节端序反转位序。
- **F05**：`c=(cR,cG,cB)`，每一分量为相应 RGB 通道全图均值除以 255，范围为 `[0,1]`。
- **F06**：图片特征为 `(64 位 b,c)`。保存与恢复须保留足以按同样规则比较的值，误差不大于 `1e-12`；不得压成改变排序的低精度格式。
- **F07**：任意常量色图片的 64 位均为 1；不得将等于均值的位清零。8×8 图像仅左上像素为白、其余为黑时，仅 bit 0 为 1。
- **F08**：非整除尺寸验收覆盖 9×17 等矩阵，检查 floor 分区及 64 单元等权。不得以库默认缩放到 8×8 替代 F02–F03。

## 索引与查询

- **Q01**：索引不持久化原始图片；保存 `image_id`、特征及用于 I03 的输入内容身份。身份表示方式未选，不能降低“像素完全相同”的判定要求。
- **Q02**：查询接受已解码图片或索引内 `image_id`。图片遵守相同输入与特征规则；id 不存在返回 `NOT_FOUND`。查询不得添加索引内容。
- **Q03**：原始整数 Hamming 距离 `h=popcount(b XOR qb)`，归一化值 `h'=h/64`。
- **Q04**：颜色距离 `d=(abs(cR-qR)+abs(cG-qG)+abs(cB-qB))/3`；总距离 `D=0.75*h'+0.25*d`。不得改用欧氏距离或预先舍入两个分量。
- **Q05**：仅保留 `D<=max_distance` 的候选，等于门限时包含。`max_distance` 须为 `[0,1]` 内有限数，否则返回 `INVALID_THRESHOLD`。
- **Q06**：k 须为 1–100 的整数，否则返回 `INVALID_K`。候选不足 k 时全部返回，空索引返回空数组。
- **Q07**：按 D 升序，D 相等时按 `image_id` 的 Unicode code point 升序稳定决胜；不得使用插入顺序、locale 或显示文件名破平局。
- **Q08**：以索引内 id 查询，仅排除该 id 自身；相同内容的其他 id 仍可返回。图片查询不做隐式自排除。
- **Q09**：每项返回 `image_id`、D、原始整数 h、颜色距离 d。显示可另行格式化，排序及门限判断使用未舍入数值。
- **Q10**：初版须返回与全量精确扫描相同的结果。内部索引结构可选，但未经接受不得采用近似检索、提早截断或丢弃候选来提高性能。

## 持久性与整体验收

- **A01**：保存全部 id、有效特征和内容身份；恢复后添加重放、冲突、删除、查询均须与不中断执行一致，不能仅恢复查询结果。
- **A02**：除输入、特征、查询距离的独立向量外，须组合验收：同像素不同 id、添加后修改调用者矩阵、删除重加、同距离平局、阈值恰好相等、k 超出现有数量、恢复后重放。
- **A03**：固定主机 H1 上，10000 张已建索引图片、单线程、k=10 时，查询 p95 须不大于 50ms。计时包括查询特征提取、距离计算及排序，不包括加载图片和保存索引。
- **A04**：p95 使用 nearest rank：N 个样本升序排列，取第 `ceil(0.95*N)` 个，位置从 1 起。无样本报告 `unavailable`，不得报告 0。
- **A05**：未测量不能认定达标。不同主机、图片集、解码条件或近似检索配置的结果不得充作同条件提升。逐次参数与原始实验结果由运行输出持有，不堆入本文。
- **A06**：语言、依赖、索引结构、快照格式尚未选择，不属于所有者已接受的具体实现约束。当前没有可引用的实现或性能证据。

具体未决选择、待明确的验收条件和实施进度由当前工作计划维护；本文不推定其答案。
