# Mosaic 总体规范

本文承接项目所有者已接受的产品契约。I、F、Q、A 编号沿用接受要求；特征与检索的详细定义由下列技术规范维护，三个规范共同定义一次整体发布和验收的工具。

## 目的与边界

Mosaic 在本地主机检索重复或相似图片。调用者传入已经解码的 RGB 像素矩阵；工具负责输入处理、内部特征、索引、查询和保存恢复。不包括图片格式解码、网络服务或 GUI。

特征、索引和检索仅供工具内部使用，不提供外部 SDK 或模块版本兼容发布，也没有分开的团队和独立模块验收。

- [特征规范](features.md)负责 F01–F08：亮度、网格、位序、颜色特征、精度和独立向量。
- [检索规范](retrieval.md)负责 Q01–Q10：索引记录、距离、查询参数、候选与排序。

## 输入与状态

| 编号 | 接受契约 |
|---|---|
| I01 | 图片是非空 H×W×3 整数 RGB 矩阵，通道取值 0–255。非法维度、非整数或越界返回 `INVALID_IMAGE`，索引状态不变。 |
| I02 | H 或 W 小于 8 返回 `IMAGE_TOO_SMALL`。不能复制像素或插值放大输入以绕过限制。 |
| I03 | `image_id` 是区分大小写的 UTF-8 标识。同 id、像素完全相同的重复添加返回原确认，不重建特征；同 id、不同像素返回 `ID_CONFLICT`，状态不变。 |
| I04 | 特征与确认只从成功接受的原像素派生，不自动旋转、裁剪或做 EXIF 修正。矩阵行列顺序由调用者给出。 |
| I05 | 添加、删除、查询按调用顺序串行执行；初版没有并发写承诺。 |
| I06 | 单图添加失败不留下部分特征或 id。批添加按数组顺序逐项执行；某项失败不回滚其他成功项。 |
| I07 | 删除不存在的 id 是幂等成功。删除存在的 id 后不得再返回旧特征；之后可重加该 id，并按新图片处理。 |
| I08 | 不修改调用者矩阵；输入返回后，调用者的后续修改不能改变已接受的索引内容。 |

## 保存与恢复

**A01：**保存包含全部 id、有效特征和用于内容身份判定的信息。恢复后的添加重放、冲突、删除和查询行为须与不中断执行一致，不能只恢复查询结果。原图持久化限制和内容身份要求见检索规范 Q01；特征精度要求见特征规范 F06。

## 整体验收

以下验收与两个技术规范的独立向量一起适用。契约已接受不代表实现已达标。

| 范围 | 必须建立的结果与验收方法 |
|---|---|
| I01–I02 | 用空矩阵、非法形状、非整数、越界和任一边不足 8 的输入验证错误；比较失败前后的索引可观察状态。检查没有暗中放大。 |
| I03–I04 | 重放同 id 同像素应返回原确认，且观察到未重建特征；同 id 改像素应冲突且状态不变。用行列不对称图验证保持调用者方向、原像素语义。 |
| I05–I08 | 顺序执行添加/删除/查询和含失败项的批添加，验证逐项提交、无失败残留、幂等删除、删除后无旧特征和删除重加。验证输入矩阵未被修改，以及返回后修改调用者矩阵不改变索引。 |
| A01 | 对同一操作序列分别不中断执行和保存后恢复执行，比较添加重放、冲突、删除与查询行为；覆盖全部 id 和特征/身份恢复。 |
| A02 | 除输入、特征、距离独立向量外，组合覆盖：同像素不同 id、添加后修改调用者矩阵、删除重加、同距离平局、阈值恰好相等、k 超出现有数量、恢复后重放。不得仅以单模块测试替代这些组合。 |
| Q10 | 查询结果须与全量精确扫描一致；具体范围见检索规范的验收。 |
| A03 | 在固定主机 H1、10000 张已建索引图片、单线程、k=10 下，查询 p95≤50ms。计时包含查询特征计算与距离排序，不含加载图片和保存索引。 |
| A04 | p95 按 nearest rank：将 N 个样本升序排列，取第 ceil(0.95×N) 个，位置从 1 开始。没有样本时报告 `unavailable`，不能报告 0。用已知样本验证统计方法。 |
| A05 | 未测量不能认定性能达标。不同主机、图片集、解码条件或近似检索配置的结果不能当作同条件提升。逐次参数和原始实验结果由运行输出持有，不积累在规范中。 |

**A06：**语言、依赖、索引结构和快照格式未被指定为已接受产品约束。待选择和待验证工作由工作计划维护。
