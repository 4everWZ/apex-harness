# Mosaic 特征与检索规范

本文件维护已接受的内部算法细节及其独立验收，覆盖 F01–F08 与 Q03–Q10。算法不是独立发布的接口；技术选型不改变这里的数值和结果语义。

## 特征

输入为通过整体输入规则的 H×W×3 RGB 矩阵。行、列从 0 开始。

1. **亮度（F01）**：每个像素计算 `L=(299R+587G+114B)/1000`。不舍入为整数，不做 gamma 修正。
2. **网格（F02）**：用 8×8 网格覆盖原矩阵。单元 `(i,j)` 的行区间为 `[floor(i*H/8), floor((i+1)*H/8))`，列区间为 `[floor(j*W/8), floor((j+1)*W/8))`，`i,j∈{0,…,7}`。不得用均匀取样点代替分区均值。
3. **均值（F03）**：`m[i,j]` 为该单元全部像素亮度的算术平均；`mbar=(Σi Σj m[i,j])/64`。全局均值是 64 个单元均值等权平均，不是原图所有像素亮度均值。
4. **位特征（F04）**：`b[i,j]=1` 当且仅当 `m[i,j]>=mbar`，否则为 0。按行优先映射到 `bit(8*i+j)`，从 bit 0 到 bit 63；不得按字节端序反转位序。
5. **颜色（F05）**：对全图 R、G、B 各自取算术平均再除以 255，得到 `c=(cR,cG,cB)`，每个分量在 `[0,1]`。

图片特征为 `(64 位 b,c)`。保存和恢复应保留足以按同样规则比较的值，误差不大于 `1e-12`；不得压成会改变排序的低精度格式（F06）。这不是将检索中的相等关系改为容差比较的许可。

## 距离与结果

设候选的特征为 `(b,c)`，查询特征为 `(qb,q)`：

- 原始整数 Hamming 距离 `h=popcount(b XOR qb)`，归一化距离 `h'=h/64`（Q03）。
- 颜色距离 `d=(abs(cR-qR)+abs(cG-qG)+abs(cB-qB))/3`（Q04）。
- 总距离 `D=0.75*h'+0.25*d`（Q04）。不得改用欧氏距离，也不得先将分量舍入。

查询参数 `max_distance` 必须为 `[0,1]` 内的有限数；非法返回 `INVALID_THRESHOLD`。只保留 `D<=max_distance`，恰好相等时包含（Q05）。`k` 必须为 1–100 的整数；非法返回 `INVALID_K`（Q06）。

结果按未舍入的 D 升序；D 相等时，按 `image_id` 的 Unicode code point 升序稳定决胜（Q07），不得按插入顺序、locale 或显示文件名破平局。排序后最多返回 k 个；不足 k 则全部返回，空索引返回空数组（Q06）。

使用索引内 id 查询时只排除该 id；其他内容相同但 id 不同的条目可以返回。图片查询不做隐式自排除（Q08）。每个结果返回 `image_id`、D、原始整数 h 和颜色距离 d。显示值可另行格式化，门限与排序须用未舍入数值（Q09）。

初版须与全量精确扫描结果相同（Q10）。内部索引结构可后续选择；未经接受不得采用近似检索、提早截断或通过丢候选提速。

## 独立验收

验收应由上述公式独立计算期望值，不能以被测实现自身的结果作为唯一参照。

| 要求 | 验收向量或检查 |
|---|---|
| F01 | 用含非整数亮度的 RGB 组合检查加权公式、小数保留以及未做 gamma 修正。 |
| F02–F03、F08 | 使用非整除尺寸，例如 9×17，逐单元检查 floor 区间覆盖的原像素与单元均值；构造不同大小单元亮度不同的情况，区别 64 单元等权平均与像素等权平均。不能以库默认缩放到 8×8 代替。 |
| F04、F07 | 任意常量色图片均应生成全 1 的 64 位；8×8 中仅左上像素白、其余黑时，仅 bit 0 为 1。另用非对称分布检查行优先位序。 |
| F05–F06 | 按全图通道均值检查颜色分量；保存/恢复后检查数值误差上限以及门限、排序行为未变。 |
| Q03–Q04 | 用已知位异或与通道均值向量分别验证 h、h/64、L1 颜色距离及 0.75/0.25 权重；包含可区分欧氏距离和分量预舍入的向量。 |
| Q05–Q06 | 检查门限 0、1、恰好等于 D、有限区间外值及非有限值；k 检查 1、100、非整数和区间外值。有效参数下覆盖空索引和不足 k 个候选。 |
| Q07–Q09 | 同 D 候选以不同插入顺序及大小写、非 ASCII id 验证 Unicode code point 决胜；验证 id 查询只排除自身、图片查询不隐式排除及完整返回字段。使用接近但不相等的 D 检查未舍入排序和门限。 |
| Q10 | 用相同输入、门限、k，对待选索引路径与独立全量精确扫描比较候选、顺序及返回数值；不能仅比较结果条数。 |

恢复后重放、状态组合及性能的验收由整体规范维护。
