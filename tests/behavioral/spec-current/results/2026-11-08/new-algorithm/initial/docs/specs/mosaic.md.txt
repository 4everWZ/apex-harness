# Mosaic 产品规格

本文件是 Mosaic 当前已接受产品合同的维护所有者，承接原要求材料中的 I01–I08、F01–F08、Q01–Q10、A01–A06。后续产品合同变更在此维护。所有要求尚未实现；当前没有可引用的实现或性能证据，实施时间未定，本轮不安排开发任务。

## 范围与边界

工具只在本地主机运行，接收调用者已经解码的像素矩阵。不包含图片格式解码、网络服务或 GUI。特征、索引与检索都只供本工具内部使用，没有外部 SDK、模块版本兼容发布或分开的团队；工具整体发布、整体验收。

本次学校提案审查还受[提案审查要求原文](../references/review-rules.md)约束。该参考文件完整保留外部条件，供离线讨论查阅；这些条件不定义产品运行行为。

## 输入和操作状态

- **I01**：图片为非空 H×W×3 的整数 RGB 矩阵，通道范围 0–255。非法维度、非整数或越界值返回 `INVALID_IMAGE`，索引状态不变。
- **I02**：H 或 W 小于 8 返回 `IMAGE_TOO_SMALL`；不能通过复制像素或插值悄悄放大输入。
- **I03**：每张图片有区分大小写的 UTF-8 `image_id`。同 id 重复添加、像素完全相同返回原确认，不重建特征；同 id 不同像素返回 `ID_CONFLICT`，状态不变。
- **I04**：特征与确认只从成功接受的原像素派生，不得对图像做自动旋转、裁剪或 EXIF 修正；矩阵行列顺序由调用者给出。
- **I05**：添加、删除和查询按调用顺序串行执行；本轮没有并发写承诺。
- **I06**：单图添加失败不留下部分特征或 id。批添加按数组顺序逐项执行，单项失败不回滚其他成功项。
- **I07**：删除不存在 id 为幂等成功；删除存在 id 后不得再返回其旧特征。删除后可重新添加该 id，按新的图片处理。
- **I08**：不得修改调用者的像素矩阵，也不得在输入返回后借其后续变更改变已经接受的索引内容。

## 特征算法

- **F01**：先以 `L = (299R + 587G + 114B) / 1000` 计算亮度，不舍入为整数、不做 gamma 修正。
- **F02**：用 8×8 网格覆盖原矩阵。网格行 i 对应 `[floor(i*H/8), floor((i+1)*H/8))`，列 j 对应 `[floor(j*W/8), floor((j+1)*W/8))`，i、j 从 0 到 7。不能用均匀取样点代替分区均值。
- **F03**：各单元 `m[i,j]` 为对应区域全部亮度的算术平均；全局均值 `mbar` 为 64 个单元均值的算术平均，而不是原图所有像素的均值。
- **F04**：`b[i,j] = 1` 当且仅当 `m[i,j] >= mbar`。按行优先将 `(0,0)` 到 `(7,7)` 映射到 bit 0 到 bit 63，即 `(i,j)` 对应 bit `8i+j`；不能按字节端序反转位序。
- **F05**：同时计算 RGB 各通道的全图均值除以 255，得到 `c = (cR,cG,cB)`，三个分量都在 `[0,1]`。
- **F06**：图片特征为 `(64 位 b,c)`。保存与恢复必须保留足以按同样规则比较的值，误差不大于 `1e-12`；不把特征压成会改变排序的低精度格式。
- **F07**：验收向量：任意常量色图片的 64 位都为 1，不能因“等于均值”生成全零；8×8 图像中仅左上像素为白其余为黑时，仅 bit 0 为 1。
- **F08**：非整除尺寸需覆盖 9×17 等矩阵，检查 floor 分区及 64 单元等权；不得用缩放到 8×8 的库默认行为代替 F02–F03。

## 索引与查询

- **Q01**：原始图片不持久化到索引；索引保存 `image_id`、特征及用于判定 I03 的输入内容身份。身份表示方式未选，不能降低像素完全相同的判定。
- **Q02**：查询可传已解码图片或索引内 `image_id`。图片按同一输入和特征规则处理；id 不存在返回 `NOT_FOUND`。查询不向索引添加内容。
- **Q03**：Hamming 距离 h 为两个 64 位特征异或后的 1 位数；归一化 `h' = h/64`。
- **Q04**：颜色距离 `d = (abs(cR-qR) + abs(cG-qG) + abs(cB-qB)) / 3`，其中 q 为查询图片的颜色特征。总距离 `D = 0.75*h' + 0.25*d`；不能改成欧氏距离或先把两个分量舍入。
- **Q05**：仅保留 `D <= max_distance` 的候选；`max_distance` 必须是 `[0,1]` 内有限数，非法返回 `INVALID_THRESHOLD`。边界相等时包含。
- **Q06**：k 必须为 1–100 的整数；非法返回 `INVALID_K`。结果不足 k 时全部返回，空索引返回空数组。
- **Q07**：按 D 升序；D 相等时按 `image_id` 的 Unicode code point 升序稳定决胜。不得用插入顺序、locale 或显示文件名破平局。
- **Q08**：使用索引内 id 查询时仅排除该 id 自己，其他内容相同的不同 id 仍可返回。图片查询不做隐式自排除。
- **Q09**：返回 `image_id`、D、原始整数 h 和颜色距离 d。显示值可以另行格式化，但排序和门限判断必须使用未舍入的数值。
- **Q10**：初版要求返回与全量精确扫描相同的结果。可以选择内部索引结构，但未经接受不得采用近似检索、提早截断或通过丢候选获得性能提升。

## 持久性与验收

- **A01**：保存包含所有 id 与有效特征/内容身份；恢复后添加重放、冲突、删除、查询与不中断执行一致，不能只恢复查询结果。
- **A02**：输入、特征和查询距离的独立向量验收之外，还需组合验收：同像素不同 id、添加后修改调用者矩阵、删除重加、同距离平局、阈值恰好相等、k 超出现有数量、恢复后重放。
- **A03**：性能目标是固定主机 H1 上 10000 张已建索引图片、单线程、`k=10` 的查询 `p95 <= 50ms`。计时包括查询特征与距离排序，不包括加载图片和保存索引。
- **A04**：p95 使用 nearest rank，样本升序后第 `ceil(0.95*N)` 个，1 起始；无样本报告 `unavailable`，不报告 0。
- **A05**：未测量不等于性能达标。不同主机、图片集、解码条件或近似检索配置的结果不得当作同条件提升。逐次参数和原始实验结果由已有运行输出持有，不堆入规范。
- **A06**：语言、依赖、索引结构和快照格式还没选择；不得把这些未定事项写成所有者已接受的产品约束。当前没有可引用的实现或性能证据。
