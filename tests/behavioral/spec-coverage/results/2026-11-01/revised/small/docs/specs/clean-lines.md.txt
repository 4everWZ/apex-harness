# clean-lines 规范

## 用途与范围

`clean-lines` 是供本地编辑器调用的命令行工具，从标准输入接收文本，将非空行去重、排序后写到标准输出。它只有一个消费者，整体发布和验收；本文件维护整个工具的已接受契约，内部处理步骤不另立规范。

接口只有 stdin、stdout、stderr 和可选参数 `--reverse`。不接受文件路径参数，不原地修改文件。实现语言与依赖未指定。

## 行为契约

以下 C01–C10 保留传入要求的标识，供实现和验收定位。

| 标识 | 必须满足的行为 |
|---|---|
| C01 | stdin 必须按严格 UTF-8 解码。遇到非法 UTF-8，退出码为 2，stderr 给出简短原因，stdout 为零字节；即使非法字节位于合法文本之后，也不能先输出部分结果。 |
| C02 | 接受 LF 和 CRLF 行分隔符。每行只移除行终止符，保留行内容的其他字符，不执行空格 strip。 |
| C03 | 只删除长度为零的行。仅含空格的行必须保留。 |
| C04 | 按字符串完全相等去重，区分大小写，不进行 Unicode 规范化。 |
| C05 | 按 Unicode code point 升序进行字符串排序：依次比较各位置的 code point；一个字符串是另一个的前缀时，短字符串在前。不使用 locale 排序。 |
| C06 | stdout 使用 UTF-8 编码，换行统一为 LF，每个保留行后恰有一个 LF。空输入或过滤后没有保留行时，输出零字节。 |
| C07 | `--reverse` 只反转最终升序排序结果，不改变去重规则和空行定义。 |
| C08 | 成功退出 0；未知参数退出 2，stderr 提示原因，stdout 为零字节。文件路径同样不是合法参数。 |
| C09 | 输入依次为 `b`、空行、`A`、`b`、一个空格的行，输出必须依次为一个空格的行、`A`、`b`；CRLF 输入的输出仍使用 LF。 |
| C10 | 验收必须覆盖空输入、纯空行、重复行、非 ASCII、带空格行、reverse，以及非法输入时 stdout 的原子性。 |

可以按读取、过滤、去重、排序、写出组织实现；这些步骤的具体模块划分不构成外部兼容性承诺。必须在确认输入合法后才产生结果，以满足 C01 的错误输出约束。

## 验收

下表中的输入和输出均为转义表示：`\n` 表示 LF，`\r` 表示 CR，`\uXXXX` / `\UXXXXXXXX` 表示对应 Unicode 字符。有效文本按 UTF-8 编码后送入 stdin；输出按精确字节比较，不忽略空格或换行。`空` 表示零字节。

所有成功案例同时断言退出 0。所有失败案例同时断言退出 2、stderr 有简短原因、stdout 为零字节。

| 场景与要求 | 参数、输入 | 预期 stdout / 验证内容 |
|---|---|---|
| 空输入（C06、C10） | 无参数；空 | 空 |
| 纯空行（C02、C03、C06、C10） | 无参数；`\n\r\n\n` | 空 |
| 已接受示例（C03–C06、C09） | 无参数；`b\n\nA\nb\n \n` | ` \nA\nb\n` |
| CRLF 转换（C02、C06、C09） | 无参数；`b\r\n\r\nA\r\nb\r\n \r\n` | ` \nA\nb\n`，没有 CR 字节 |
| 空格内容不变（C02、C03、C10） | 无参数；` a \na\n \n  \n` | ` \n  \n a \na\n` |
| 大小写与完全相等去重（C04、C10） | 无参数；`a\nA\na\nA\n` | `A\na\n` |
| 非 ASCII 与规范化边界（C04、C05、C10） | 无参数；`\u00e9\ne\u0301\n\u00e9\n` | `e\u0301\n\u00e9\n`；组合形式与预组合形式都保留 |
| 按 code point 比较（C05、C10） | 无参数；`\U00010000\n\ue000\naa\na\n` | `a\naa\n\ue000\n\U00010000\n`；覆盖前缀及补充平面字符 |
| 仅反转结果（C07、C10） | `--reverse`；`b\n\nA\nb\n \n` | `b\nA\n \n`；空行仍删除，重复仍合并，空格仍保留 |
| reverse 空结果（C06、C07） | `--reverse`；`\n` | 空 |
| 非法 UTF-8 与输出原子性（C01、C10） | 无参数；有效字节 `61 0a` 后接非法字节 `ff` | 失败；stdout 为空。另检查截断的多字节序列，例如 `e2 82`，也失败 |
| 未知参数（C08） | `--unknown`；`a\n` | 失败；stdout 为空 |
| 文件路径不是参数（C08） | `input.txt`；`a\n` | 失败；stdout 为空，不修改文件 |

验收通过需要实际运行实现并检查上述输出、编码、退出码和错误流；本文中的案例是验收要求，不代表已有运行证据。
