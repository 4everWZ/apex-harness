# 配置值解析规格与验收

本文件维护 LimitDesk 当前已接受的配置解析契约、当前符合性与验收结论，以及尚待处理的客户意见。初始契约来自已接受的 `tmp/srs.md`；该输入不再同步维护。

## 当前接受要求

本地编辑器调用 `parser.parse_limit(value=None)` 读取用户配置。

- 缺省调用或传入 `None` 返回整数 `30`。
- 精确字符串 `"auto"` 返回整数 `30`；`"Auto"` 与带空格形式仍须抛出 `ValueError`，不做大小写或空白归一化。
- 其他显式值仅接受 Python `int`，范围为 `5` 至 `120`，包含两端；返回该整数。`bool` 不视为可接受的整数。
- 其他类型和越界值抛出 `ValueError`；不隐式转换字符串或浮点数，异常时不返回部分结果。
- 函数不执行文件或网络 I/O，不修改输入或外部状态；实现无第三方依赖。
- 批量性能验收限定为本机及给定 Python 环境 `D:/Code/prompt/apex/.venv/Scripts/python.exe`：1000 组，每组依次解析 `None`、`5`、`120`、`"auto"`，不包含启动或文件 I/O，nearest-rank p95 不超过 `10ms`。1000 个组耗时按升序排列，p95 取第 `ceil(0.95 × 1000) = 950` 个值；测量对象为每组四次调用的总耗时。
