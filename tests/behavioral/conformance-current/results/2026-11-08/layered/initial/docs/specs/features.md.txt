# Mosaic 特征规范

本规范拥有 Mosaic 内部图片特征的数学定义、存储精度和独立向量验收（F01–F08）。仅对符合总体规范输入要求的原像素计算，不引入缩放、旋转或其他预处理。

## 亮度与网格

**F01** 对原矩阵每个像素计算：

`L = (299*R + 587*G + 114*B) / 1000`

不舍入成整数，不做 gamma 修正。

**F02** 用 8×8 网格覆盖原矩阵。对于 `i,j ∈ {0,...,7}`：

- 行区间为 `[floor(i*H/8), floor((i+1)*H/8))`；
- 列区间为 `[floor(j*W/8), floor((j+1)*W/8))`。

单元包含相应行列区间的全部像素，不能用均匀采样点替代分区。

**F03** `m[i,j]` 为该单元全部像素亮度的算术平均。全局均值为：

`mbar = (Σ(i=0..7) Σ(j=0..7) m[i,j]) / 64`

64 个单元等权；当单元像素数不同时，不得用原图所有像素亮度的均值替代 `mbar`。

## 位特征与颜色特征

**F04** `b[i,j] = 1` 当且仅当 `m[i,j] >= mbar`，否则为 0。按行优先把 `(0,0)` 到 `(7,7)` 映射到 bit 0 到 bit 63，即 `bit_index=8*i+j`。不得按字节端序反转位序。

**F05** 分别求 RGB 每个通道的全图均值并除以 255：

`cR = ΣR / (H*W*255)`，`cG = ΣG / (H*W*255)`，`cB = ΣB / (H*W*255)`。

得到 `c=(cR,cG,cB)`，每个分量均在 `[0,1]`。颜色均值按全图像素计算，不使用亮度网格的单元等权平均。

**F06** 图片特征为 `(64 位 b, c)`。保存与恢复须保留足以按相同规则比较的值，误差不大于 `1e-12`；不得压缩为会改变排序的低精度格式。本规范未指定内部数值类型和表示方式。

## 独立向量验收

- **F07：常量图。** 任意符合输入条件的常量色图片，64 位全部为 1；相等分支不得产生全零。
- **F07：单白点。** 8×8 图片仅左上像素为白，其余为黑，仅 bit 0 为 1。
- **F08：不整除尺寸。** 覆盖 9×17 等矩阵，逐项检查 floor 分区及 64 个单元等权。不得以库默认缩放到 8×8 替代 F02–F03。

独立向量需要能区分错误分区、原像素加权均值、错误位序和未经接受的预处理。
