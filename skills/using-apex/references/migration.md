# Consolidated Skill Names

Read this only when a user or automation refers to a pre-consolidation APEX or
Superpowers workflow name.

| Previous name | Current route |
|---|---|
| `apex-governance` | `governing-project-work` |
| `brainstorming`, `writing-plans` | `shaping-solutions` |
| `using-git-worktrees`, `finishing-a-development-branch` | `managing-git` |
| `dispatching-parallel-agents`, `subagent-driven-development`, `requesting-code-review`, `receiving-code-review` | `coordinating-subagents` |
| `executing-plans` | inline execution, or `coordinating-subagents` when delegation is justified |
| `systematic-debugging` | `debugging-systematically` |
| `test-driven-development` | `testing-changes` when its current trigger matches |
| `verification-before-completion` | ordinary proportionate verification, or `testing-changes` when a strategy decision is needed |

Translate user intent, then evaluate the current trigger and authority boundary.
Direct lookup of a deleted name is intentionally unsupported; do not claim an
alias was loaded.
