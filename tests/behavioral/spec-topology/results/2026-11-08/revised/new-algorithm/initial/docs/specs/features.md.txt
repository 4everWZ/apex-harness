# Mosaic 特征规范

本规范负责已接受的 F01–F08。输入为有效的 H×W×3 RGB 矩阵，H、W 均不小于 8；行列顺序沿用调用者输入。

## 亮度与分区

**F01：**每个像素的亮度为：

`L = (299R + 587G + 114B) / 1000`

不将亮度舍入为整数，不做 gamma 修正。

**F02：**8×8 网格完整覆盖原矩阵。i、j 从 0 到 7，第 (i,j) 单元的行区间为 `[floor(i×H/8), floor((i+1)×H/8))`，列区间为 `[floor(j×W/8), floor((j+1)×W/8))`。两端使用原矩阵坐标，右端不包含。不能用均匀取样点替代区域均值。

**F03：**`m[i,j]` 是该区域所有像素亮度的算术平均；`mbar = sum(m[i,j])/64` 是 64 个单元均值的等权平均。非整除尺寸下单元大小可能不同，不能将 mbar 改成全图像素亮度均值。

## 位特征与颜色

**F04：**`b[i,j] = 1` 当且仅当 `m[i,j] >= mbar`，否则为 0。行优先从 (0,0) 到 (7,7) 对应 bit 0 到 bit 63，即位权为 `2^(8i+j)`。不得按字节端序反转位序。

**F05：**RGB 各通道的全图算术平均分别除以 255，得到 `c=(cR,cG,cB)`，各分量均在 [0,1]。

**F06：**特征为 `(64 位 b, c)`。保存与恢复须保留足以依同样规则比较的值，误差不大于 1e-12；不得压成会改变排序的低精度格式。该误差界限不授权对查询距离舍入或用容差改写排序规则。

## 独立验收

| 范围 | 向量与检查 |
|---|---|
| F01 | 用独立计算的 RGB 加权亮度检验非整数亮度，覆盖不会被整数舍入或 gamma 修正意外掩盖的输入。 |
| F02–F03、F08 | 包含 9×17 等非整除尺寸。依 floor 区间独立核对每个单元的边界、区域像素均值和 64 单元等权均值；使用能区分全图均值、均匀采样和默认缩放的非均匀像素。不能用库默认缩放到 8×8 代替规定分区。 |
| F04、F07 | 任意常量色图的 64 位全为 1，不能在等于均值时生成全零。8×8 图仅左上角白、其余黑时，仅 bit 0 为 1。另检查不对称位置以识别行列或位序反转。 |
| F05 | 独立核对各通道全图均值及除以 255 的结果，包括端点与非整除均值。 |
| F06 | 保存恢复后核对位值、颜色误差≤1e-12，并以会暴露精度损失的距离排序案例检查排序未被低精度表示改变。 |

这些检查用于未来实现验收；文档中的定义本身不构成实现已通过的证据。
