# Mosaic 索引与查询规范

本规范拥有内部索引、检索距离、候选选择、结果顺序以及保存恢复的契约（Q01–Q10、A01）。图片查询使用[特征规范](features.md)定义的相同特征。

## 索引与查询入口

**Q01** 原始图片不持久化到索引。索引保存 `image_id`、有效特征，以及足以判定 I03 完全相同输入的内容身份。身份表示方式未选，不得以该选择降低像素完全相同的判定。

**Q02** 查询接受已解码图片或索引内 `image_id`。图片遵守相同的输入及特征规则；id 不存在返回 `NOT_FOUND`。查询不得向索引添加内容。

**Q08** 使用索引内 id 查询，仅排除该 id 自己；像素相同的其他 id 仍可返回。图片查询不执行隐式自排除。

## 距离

对于候选特征 `(b,c)` 和查询特征 `(qb,q)`：

- **Q03** `h = popcount(b XOR qb)`，为 0–64 的原始整数；`h' = h/64`。
- **Q04** `d = (abs(cR-qR) + abs(cG-qG) + abs(cB-qB))/3`。
- **Q04** `D = 0.75*h' + 0.25*d`。

不得使用欧氏颜色距离；不得先舍入两个分量再组合。

## 参数、筛选与结果

| 要求 | 已接受契约 |
|---|---|
| Q05 | `max_distance` 必须为 `[0,1]` 内有限数，否则返回 `INVALID_THRESHOLD`。仅保留 `D <= max_distance` 的候选，门限相等时包含。 |
| Q06 | `k` 必须为 1–100 的整数，否则返回 `INVALID_K`。结果不足 k 时全部返回；空索引返回空数组。 |
| Q07 | 候选按 D 升序；D 相等时按 `image_id` 的 Unicode code point 升序稳定决胜。不得使用插入顺序、locale 或显示文件名决胜。 |
| Q09 | 每项返回 `image_id`、D、原始整数 h 和颜色距离 d。显示值可另行格式化，排序与门限判断必须使用未舍入数值。 |
| Q10 | 初版结果必须与全量精确扫描相同。内部索引结构可选，但未经接受不得采用近似检索、提早截断或丢候选以提升性能。 |

按上述排除、门限和顺序规则取得最多 k 项。调用参数的外部表达形式尚未选定，不改变这些规则。

## 保存与恢复（A01）

保存内容包括全部 id、有效特征和输入内容身份；不得只保存查询结果。恢复后，添加重放、内容冲突、删除与查询必须和不中断执行一致，包括 I03 的重复添加语义及 I07 的删除重加语义。

保存恢复遵守 F06 的精度和排序要求；快照格式尚未选择。

## 验收范围

独立检查整数 Hamming 距离、归一化、L1 颜色距离和加权总距离，覆盖合法及非法门限、合法及非法 k、空索引、id 不存在、自排除、完全相等门限和 Unicode code point 平局。查询结果与全量精确扫描对照；保存恢复前后对照完整操作序列，不能仅比一次查询输出。

跨输入、特征、状态和查询的组合验收与性能要求由总体规范拥有。
