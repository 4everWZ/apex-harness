# clean-lines 接受要求

这是一个单一消费者、整体发布和验收的小工具；内部各步骤没有独立的消费方或兼容性发布。

- C01: 从 stdin 读取严格 UTF-8；非法 UTF-8 时退出 2，stderr 给简短原因，stdout 必须为空。
- C02: 接受 LF 与 CRLF 分隔；每行仅去除行终止符，不 strip 空格。
- C03: 仅删除长度为零的行；仅含空格的行要保留。
- C04: 按字符串完全相等去重，区分大小写；不能做 Unicode 规范化。
- C05: 按 Unicode code point 升序排序；不使用 locale 排序。
- C06: 输出 UTF-8、LF 换行，每个保留行以一个 LF 结束；空输入或过滤后为空则输出零字节。
- C07: --reverse 只反转最后排序结果，不改变去重与空行定义。
- C08: 成功退出 0；未知参数退出 2，stderr 提示，stdout 为空。没有文件路径参数，没有原地修改文件。
- C09: 验收例：输入 b、空行、A、b、空格行时，输出依次为空格行、A、b。CRLF 输入输出仍为 LF。
- C10: 验收覆盖空输入、纯空行、重复行、非 ASCII、带空格行、reverse 与非法输入的 stdout 原子性。
