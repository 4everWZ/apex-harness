# Relay Worker Protocol v1

本文件维护外部 worker 的已接受协议和独立兼容性验收要求（R13–R22）。协议传输方式与完整请求、响应 schema 尚未决定。两个外部提供方应能据本协议实现插件，不依赖服务器自带 worker 的内部实现。

## 领取与有效期

- **R13：** 领取返回 `job_id`、`attempt_id`、`lease_token`、`lease_expires_at`、`job_type` 和 `payload`。每次重新领取都必须改变 `attempt_id`。
- **R14：** Lease 默认 60 秒，worker 每 20 秒心跳。成功心跳从服务端当前时间延长 60 秒。在 `lease_expires_at` 时刻及之后 lease 即失效。
- **R15：** 心跳和结果均必须携带 `attempt_id` 与 `lease_token`。两者不匹配或 lease 已过期时返回 `STALE_LEASE`，不更新任务状态或结果。
- **R16：** Lease 过期的非终态任务重新排队。旧 worker 的迟到成功不能覆盖新 attempt 的状态。

## 结果重放与重试

- **R17：** 同一有效 attempt 的相同结果重复提交返回原确认；不同结果返回 `RESULT_CONFLICT`。确认丢失后的重试不得再次执行终态转换。
- **R18：** 至多领取 3 次，首次领取计入次数。第三次 lease 过期或可重试失败后，任务进入 failed，`error_code=ATTEMPTS_EXHAUSTED`，不再派发。此规则限定 R16 中重新排队的适用次数。
- **R19：** 可重试失败不直接发布终态；尚有次数时返回 queued。不可重试失败立即 failed。

## 取消与版本

- **R20：** Worker 收到 `cancel_requested` 后应停止工作，并用当前有效 lease 确认取消。无法证明旧 attempt 已停，不代表它仍有提交结果的权限。
- **R21：** 领取结果携带 `protocol_version=1`。服务器拒绝不支持的协议版本，返回 `UNSUPPORTED_PROTOCOL`，且不改变任务。

## 外部兼容性验收

**R22：** 通过独立 conformance suite 验收外部提供方协议，不能只测试服务器自带 worker。套件至少覆盖：

| 范围 | 必须观察的结果 |
|---|---|
| R13–R14 | 必需领取字段、每次领取不同 attempt_id、默认 lease 与心跳时序；心跳从服务器当前时刻续期；到期前、恰到期、到期后三类边界 |
| R15–R16 | 错误 attempt、错误 token 和过期请求返回 STALE_LEASE，任务及结果不变；到期重排队后重新领取；旧 attempt 迟到成功不能覆盖新状态 |
| R17 | 有效 attempt 相同结果重放原确认；不同结果 RESULT_CONFLICT；模拟确认丢失再提交，终态转换只发生一次 |
| R18–R19 | 第一次计数；可重试失败有余次则 queued；第三次到期或可重试失败均以 ATTEMPTS_EXHAUSTED 失败且不再领取；不可重试失败立即 failed |
| R20 | 当前有效 lease 的取消确认；旧 attempt 无权借取消路径提交结果；与成功并发仍遵守唯一终态 |
| R21 | 版本字段为 1；不支持版本返回 UNSUPPORTED_PROTOCOL 且任务不变 |

尚未编写或运行套件，也未形成任何外部提供方符合性证据。结果相等判定及完成后重放与 lease 过期规则的交界待澄清，不以某个实现的行为默认定义。
