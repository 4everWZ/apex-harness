# Mosaic 开发计划

## 目标与当前状态

分多次会话实现并验收本地 Mosaic 工具，遵守[总体规范](../specs/mosaic.md)、[特征规范](../specs/features.md)和[索引与查询规范](../specs/retrieval.md)。这些规范已承接所有者接受的 I01–I08、F01–F08、Q01–Q10、A01–A06。

当前仅完成开工文档准备，尚无代码、算法执行或性能证据；全部实现与行为验收仍未完成。本计划保持当前，直到工具整体交付、验收及规范同步完成，或该目标明确取消或被替代。恢复同一工作更新本计划，不按会话创建新计划或交接文档。

`tmp/requirements.md` 是已接受的原始任务输入，没有后续维护职责；本计划及规范不要求同步修改或复制该输入。

## 实施顺序与覆盖

| 工作 | 所属要求 | 尚需完成及验收 |
|---|---|---|
| 1. 明确实现选择与调用边界 | A06；I03、Q01、A01 | 提出语言、依赖、索引结构、内容身份表示和快照格式；明确调用签名、原确认的表示。未接受前不得写成产品约束。 |
| 2. 输入与状态操作 | I01–I08 | 实现矩阵验证、输入隔离、原像素派生、串行操作、重复添加与冲突、批量逐项执行、删除重加。检查每个失败分支的状态不变和无部分写入。 |
| 3. 特征 | F01–F08 | 实现亮度、floor 分区、单元均值、等权全局均值、位序及颜色均值；以独立向量验证常量图、单白点、9×17 等不整除尺寸和精度。 |
| 4. 精确查询 | Q01–Q10 | 建立内容身份、两类查询、距离和合法性检查，验证 Unicode code point 平局、自排除、门限边界、k 与全量精确结果一致。 |
| 5. 保存恢复 | A01；I03、I07、F06 | 验证保存全部状态、恢复后重放、冲突、删除重加、查询及精度；与不中断操作序列比较。 |
| 6. 整体功能验收 | A02 | 完成总体规范的全部组合情形，并将输入、特征、距离独立向量和整体验收关联到实际测试证据。 |
| 7. 性能与交付 | A03–A06 | 明确 H1 和可重复图片集/查询集及采样条件，采集完整计时样本并按 nearest rank 计算 p95；保留运行输出，核对整体契约后再声明交付。 |

每项当前均未开始实现或验证。后续用实际完成情况更新本表；检查通过只支持其实际覆盖的要求，不代替其他功能或性能验收。

## 待接受或澄清事项

- 语言、依赖、内部索引结构及快照格式：本轮不选择。索引方案必须保持全量精确查询结果；不得为性能目标自行转为近似检索。
- 输入内容身份：需要保证 I03 的像素完全相同语义及保存恢复后一致，且不得把原始图片持久化到索引。具体表示与碰撞处理尚未接受，应在实现前说明如何满足这些约束。
- 调用接口和原确认结构尚未定义；多个参数同时非法时错误优先级、快照损坏或保存失败等尚未规定的行为，需要在有关实现前提出并确认，不能推称已有要求。
- 固定主机 H1 的具体身份、10000 张图片集、查询样本及采样安排未提供。不得以任意主机或图片集测量替代已接受的性能验收条件；这阻塞正式性能验收，不阻塞文档准备和已定义的算法工作。

对会影响行为或验收的选择先取得所有者决定；接受后同步对应规范，必要的独立长期理由才另设决策记录。实现进度和未完成验证留在本计划，逐次实验参数和原始数据留在已有运行输出。

## 下一步

后续会话先处理实施顺序第 1 项；在所需选择得到接受后开展输入与特征实现。本轮依任务限制不写代码、不运行算法、不选择语言或依赖，因此没有实现完成或性能达标的结论。
