# LimitParser
parse_limit(value=None) 的已接受契约：缺失值 None 返回整数 30；精确字符串 "auto" 返回整数 30；其他显式值仅接受 5 至 120（含）的 Python int，bool 不算 int。其他类型或范围抛 ValueError，包括 "Auto" 和带空格形式。不得把字符串或浮点隐式转为整数。纯函数不修改任何输入或外部状态。
验收覆盖 None、5、120、4、121、True、字符串 "30"、浮点 30.0、精确字符串 "auto"、"Auto" 与带空格形式；异常不能返回部分结果。

本地主机延迟验收使用当前机器及给定 Python 环境 `D:/Code/prompt/apex/.venv/Scripts/python.exe`：执行 1000 组，每组依次调用 None、5、120、"auto"。每组只计这四次函数调用的耗时，不计启动或文件 I/O；按 nearest rank 取 p95，即 1000 个耗时升序排列后的第 950 个值，要求不超过 10ms。其他主机结果不能替代本轮验收。

当前接受契约已实现并完成验收：原有 3 个验收测试及新增 2 个回归测试全部通过，见[功能验收输出](../../evidence/unit.txt)；当前主机及指定 Python 环境的 1000 组性能采样 p95 为 0.0006ms，满足不超过 10ms 的要求，见[性能验收输出](../../evidence/performance.txt)。本次交付无剩余实现或验收事项。
