# score-method v2 已接受变更

所有者已接受 score-method v2：W 从 64 改为 128，打分最少历史值由 16 改为 32；warmup_remaining 按 32-n 计算。标准差、epsilon=0.001、严格大于 3、先评分后插入、事件去重 128 条、错误状态不变和恢复连续性保持不变。median/MAD 方案仍未接受。

SDK 组按方法 v2 做独立兼容性验收。原来第 16/17 次输入、第 64/65 个窗口边界的验收应改为 32/33 与 128/129；数学向量应以 32 个交替 -1,+1 和 32 个 0 建立前置窗口，期望分数与布尔值不变。没有新的实验结果，也还没有实现。

evaluation protocol 仍为 v3，切分、质量指标和延迟统计定义不变。评测 reference 应指向当前接受的方法 v2，其余协议语义不改。不得据此宣称效果或性能提升。
