# Mosaic 特征计算规范

本文件维护 F01–F08 的详细定义与特征局部验收。输入须满足工具的输入契约；以下计算使用成功接受的原像素，不引入额外图像变换。

## 亮度与网格

F01：对每个像素计算亮度：

`L = (299R + 587G + 114B) / 1000`

不舍入为整数，不做 gamma 修正。

F02：以 8×8 网格覆盖原矩阵，i、j 从 0 到 7。单元 (i,j) 的行区间为：

`[floor(i×H/8), floor((i+1)×H/8))`

列区间为：

`[floor(j×W/8), floor((j+1)×W/8))`

采用半开区间，计算对应区域全部像素；不得以均匀取样点替代分区均值。

F03：`m[i,j]` 为该区域所有亮度的算术平均。全局均值为：

`mbar = (Σ(i=0..7) Σ(j=0..7) m[i,j]) / 64`

64 个单元等权；`mbar` 不是原图所有像素亮度的平均值。

## 位特征与颜色特征

F04：当且仅当 `m[i,j] >= mbar` 时，`b[i,j] = 1`，否则为 0。按行优先将 (0,0) 到 (7,7) 映射到 bit 0 到 bit 63，即位编号为 `8i+j`；不得因字节端序而反转位序。

F05：各 RGB 通道取全图像素均值，再分别除以 255，得到 `c=(cR,cG,cB)`，三个分量均在 [0,1]。颜色特征按全图像素计算，不采用 64 单元等权代替。

F06：完整图片特征为 `(64 位 b, c)`。保存与恢复须保留足以按同样规则比较的值，误差不大于 `1e-12`；不得压缩为会改变排序的低精度格式。

## 局部验收

F07 的接受向量：

- 任意常量色图片，64 位全部为 1；等于均值的情况不能生成全零。
- 8×8 图片，仅左上像素为白、其余为黑时，仅 bit 0 为 1。

F08：覆盖 9×17 等非整除尺寸，验证 floor 分区、全部区域的均值以及 64 单元等权。不得用库默认的缩放到 8×8 行为替代 F02–F03。

独立验收需能区分亮度计算、区域平均、全局平均、位序、等于均值时置位及颜色全图平均中的错误。保存恢复还需检查 F06 的比较精度及排序保持要求。
