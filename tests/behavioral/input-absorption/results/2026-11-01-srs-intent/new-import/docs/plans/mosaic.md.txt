## 后续待决事项

以下不是新增产品约束，本轮不选择答案。

- 语言与依赖、调用入口及具体参数/返回数据结构，包含“原确认”的表示。它们应服务现有语义，不构成外部 SDK 或模块兼容发布承诺。
- Q01 的内容身份表示。必须能支持像素完全相同的判断、同 id 重放和恢复；不得未经接受将精确等同降为可能碰撞的近似等同，也不得把原始图片持久化到索引。
- 内部索引结构、数值表示与快照格式。须满足精确扫描等价、数值保真和恢复后完整操作语义；性能压力不能直接授权近似检索。
- 尚未定义的可观察细节：多个参数同时非法时的错误优先级、非法 id 的处理、保存/恢复自身失败的错误与状态效果。如实现需要承诺这些行为，先明确并获得所需决定，再更新规范；不得靠实现偶然行为建立合同。
- 固定主机 H1 的具体配置、图片集、查询集合与采样安排尚待落实。保留 A03–A05 原有目标与计时范围，未测量时不宣称达标。
