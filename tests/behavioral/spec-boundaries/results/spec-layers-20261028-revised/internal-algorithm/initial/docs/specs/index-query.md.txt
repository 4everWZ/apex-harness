# Mosaic 索引与查询规范

本文件维护 Q01–Q10 的详细定义与查询局部验收。图片入口使用工具的输入契约及同一[特征规则](image-features.md)；内部索引结构不改变以下结果语义。

## 索引内容与查询入口

Q01：索引不持久化原始图片，只保存 `image_id`、特征和用于判定 I03 的输入内容身份。内容身份的表示方式尚未选择；不能降低“像素完全相同”的判定。

Q02：查询可传已解码图片或索引内 `image_id`。图片按同一输入、特征规则处理；查询 id 不存在时返回 `NOT_FOUND`。查询不向索引添加内容。

Q08：使用索引内 id 查询时，只排除该 id 自身，内容相同的其他 id 仍可返回。图片查询不做隐式自排除。

## 距离

令查询特征为 `(bq, q)`，候选特征为 `(b, c)`，其中颜色分量为 R、G、B。

Q03：原始 Hamming 距离 `h = popcount(b XOR bq)`；归一化值 `h' = h/64`。

Q04：颜色距离与总距离分别为：

`d = (abs(cR-qR) + abs(cG-qG) + abs(cB-qB)) / 3`

`D = 0.75×h' + 0.25×d`

不得改用欧氏距离，也不得先把两个分量舍入。

## 参数、筛选与结果

Q05：`max_distance` 必须是 [0,1] 内有限数，非法返回 `INVALID_THRESHOLD`。仅保留 `D <= max_distance` 的候选，边界相等时包含。

Q06：`k` 必须是 1–100 的整数，非法返回 `INVALID_K`。结果不足 k 时全部返回；空索引返回空数组。

Q07：结果按 D 升序；D 相等时按 `image_id` 的 Unicode code point 升序稳定决胜。不得以插入顺序、locale 或显示文件名破平局。

Q09：结果返回 `image_id`、D、原始整数 h 及颜色距离 d。显示值可另行格式化；排序和门限判断必须使用未舍入的数值。

Q10：初版结果必须与全量精确扫描相同。内部索引结构可另行选择；未经接受不得采用近似检索、提早截断，或通过丢弃候选获得性能提升。

## 局部验收

查询独立向量应验证 XOR 位计数、h/64、颜色 L1 平均与加权总距离，并分别验证未经舍入的筛选及排序。参数验收应覆盖有效上下界、非法范围、非有限阈值、非整数 k 及错误码。

还须验证图片/id 两种入口、未知 id、不添加查询图片、空索引、结果不足 k、自身排除边界、相同内容不同 id、Unicode code point 平局排序，以及返回的四个字段。任一内部索引方案均须对照全量精确扫描检查结果相同；组合与恢复场景由整体验收统筹。
