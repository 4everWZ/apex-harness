# Mosaic 工具规范

本文承接所有者已接受的 I01–I08、Q01、A01–A06，定义本地重复图片检索工具的整体契约；[相似度规范](similarity.md)承接 F01–F08、Q02–Q10 的技术细节。两份规范属于同一产品契约，整体发布、整体验收。契约接受不表示实现已经完成或通过验收。

## 范围与边界

工具只在本地主机运行。调用者提供已经解码的像素矩阵；工具支持单图及批量添加、删除、按图片或已索引 id 查询、保存与恢复。图片格式解码、网络服务和 GUI 不在范围内。

特征、索引和检索只供工具内部使用，不提供外部 SDK，也没有模块版本兼容发布或分开的团队。本文约定语义，不选择语言、依赖、内部索引结构或快照格式。

## 输入与状态

| ID | 接受的行为 |
|---|---|
| I01 | 图片必须为非空 H×W×3 整数 RGB 矩阵，各通道值为 0–255。非法维度、非整数或越界值返回 `INVALID_IMAGE`，索引状态不变。 |
| I02 | H 或 W 小于 8 返回 `IMAGE_TOO_SMALL`；不得以复制像素或插值悄悄放大。 |
| I03 | 每张图片有区分大小写的 UTF-8 `image_id`。同 id、像素完全相同的重复添加返回原确认，不重建特征；同 id、不同像素返回 `ID_CONFLICT`，状态不变。 |
| I04 | 特征与确认只从成功接受的原像素派生。不自动旋转、裁剪或修正 EXIF；使用调用者给定的矩阵行列顺序。 |
| I05 | 添加、删除和查询按调用顺序串行执行；当前没有并发写承诺。 |
| I06 | 单图添加失败不留下部分特征或 id。批添加按数组顺序逐项执行，单项失败不回滚其他成功项。 |
| I07 | 删除不存在的 id 为幂等成功；删除存在的 id 后不得再返回其旧特征。删除后重新添加该 id，按新图片处理。 |
| I08 | 不修改调用者像素矩阵；输入返回后，调用者后续修改矩阵不得改变已接受的索引内容。 |

上述失败、重放和删除语义约束实现中的状态转换；添加确认的具体表示尚未选择，不得因此改变“返回原确认”的语义。

## 索引内容与持久性

- **Q01：**索引保存 `image_id`、有效特征和用于 I03 的输入内容身份，不持久化原始图片。身份表示方式尚未选择，必须维持像素完全相同的判断，不能用较弱的相似判断代替。
- **A01：**保存包含全部 id、有效特征与内容身份。恢复后，添加重放、冲突、删除、查询的行为必须与不中断执行一致；只恢复查询结果不满足要求。特征的保存精度由相似度规范 F06 规定。

## 验收契约

| ID | 验收要求与检查方式 |
|---|---|
| A02 | 除独立的输入、特征与查询距离向量外，必须组合检查：同像素不同 id、添加后修改调用者矩阵、删除重加、同距离平局、阈值恰好相等、k 超出现有数量、恢复后重放。各检查同时遵循输入状态表和相似度规范，不以单个向量代替组合检查。 |
| A03 | 固定主机 H1、10000 张已建索引图片、单线程、k=10，查询 p95 ≤ 50 ms。计时包含查询特征计算及距离排序，不包含加载图片和保存索引。 |
| A04 | 使用 nearest rank：N 个耗时样本升序排列后，p95 为第 ceil(0.95×N) 个值，位置从 1 起算。无样本报告 `unavailable`，不能报告 0。 |
| A05 | 未测量不能判断性能达标。不同主机、图片集、解码条件或近似检索配置的结果，不能宣称为同条件提升。逐次参数与原始实验结果由运行输出持有，不累积到本规范。 |
| A06 | 语言、依赖、索引结构与快照格式尚未选择；不得视为已接受的产品约束。 |

整体验收还须覆盖 I01–I08、Q01、A01，以及相似度规范全部条款。正确性验收与性能验收分别给出证据；满足其中之一不代表满足另一项。
