Add rank_cards(cards) to the local desktop suggestion panel. Each card has a unique string id, integer interest, and nonnegative integer age_minutes. Use score = 2 * interest - age_minutes, sort by decreasing score then increasing id, and return the ordered ids without mutating cards. This new preference rule replaces the existing input-order display when called by the panel; retain display_ids for its existing callers. The rule is approved.
