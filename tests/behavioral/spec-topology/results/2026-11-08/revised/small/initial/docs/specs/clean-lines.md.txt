# clean-lines 规范

## 用途与范围

clean-lines 是供本地编辑器调用的命令行工具，从标准输入读取文本，去掉空行和重复行，排序后写到标准输出。工具只有一个消费者，整体发布、整体验收；内部读取、过滤、排序和写出步骤不形成独立契约或兼容性版本。

本文件维护所有者已接受的当前契约与验收要求。语言和依赖未指定，由实现者按项目环境选择。工具不接受文件路径参数，不原地修改文件。

## 命令与数据契约

| 要求 | 必须满足的行为 |
|---|---|
| C01 | 从 stdin 读取严格 UTF-8。遇到非法 UTF-8 时退出码为 2，stderr 给出简短原因，stdout 必须为零字节；即使非法字节之前已有合法行，也不得先输出这些行。 |
| C02 | 接受 LF 与 CRLF 行分隔，每行仅去除行终止符，不 strip 空格。 |
| C03 | 仅删除长度为零的行；仅含空格的行保留。 |
| C04 | 按字符串完全相等去重，区分大小写，不做 Unicode 规范化。 |
| C05 | 按 Unicode code point 升序排序，不使用 locale 排序。字符串按 code point 序列逐项比较；共同前缀相同时较短字符串在前。 |
| C06 | 输出编码为 UTF-8，行分隔为 LF；每个保留行以一个 LF 结束。空输入或过滤后为空时输出零字节。 |
| C07 | 可选参数 `--reverse` 仅反转最终排序结果，不影响去重、空行定义或其他文本内容。默认升序。 |
| C08 | 成功退出 0。未知参数退出 2，stderr 提示原因，stdout 为空。没有文件路径参数，没有原地修改文件。 |

转换关系为：解码与分行 → 删除零长度行 → 完全相等去重 → code point 升序排序 → 按需反转 → 编码输出。该关系规定结果，不限制内部模块或具体算法。stdout 只承载结果，错误原因写到 stderr。

## 验收

以下使用转义形式表示输入和预期输出的精确内容：`\n` 为 LF，`\r\n` 为 CRLF，`\uXXXX`、`\UXXXXXXXX` 表示 Unicode code point；引号不属于内容。除非法 UTF-8 案例外，输入按 UTF-8 编码。每例均须比较 stdout 的完整字节内容与退出码；错误例还须检查 stderr 有简短原因。

| 案例 | 输入与参数 | 预期结果 | 覆盖 |
|---|---|---|---|
| 所有者示例 | `"b\n\nA\nb\n \n"`；无参数 | stdout 为 `" \nA\nb\n"`；退出 0 | C02–C06、C09 |
| CRLF | `"b\r\n\r\nA\r\nb\r\n \r\n"` | stdout 为 `" \nA\nb\n"`；退出 0 | C02、C06、C09 |
| 空输入 | 零字节 | stdout 零字节；退出 0 | C06、C10 |
| 纯空行 | `"\n\r\n\n"` | stdout 零字节；退出 0 | C02、C03、C06、C10 |
| 重复和大小写 | `"a\nA\na\nA\n"` | stdout 为 `"A\na\n"`；退出 0 | C04、C05、C10 |
| 空格内容 | `"a \n a\n \n  \na\n"` | stdout 为 `" \n  \n a\na\na \n"`；退出 0 | C02–C05、C10 |
| 非 ASCII 与 code point | `"\U0001F600\n\uE000\n\u4E2D\n\u00E9\n"` | stdout 为 `"\u00E9\n\u4E2D\n\uE000\n\U0001F600\n"`；退出 0 | C05、C06、C10；可识别按 UTF-16 单元排序的错误 |
| 不规范化 | `"\u00E9\ne\u0301\n\u00E9\n"` | stdout 为 `"e\u0301\n\u00E9\n"`，两种表示均保留；退出 0 | C04、C05、C10 |
| reverse | 所有者示例输入；参数 `--reverse` | stdout 为 `"b\nA\n \n"`；退出 0 | C07、C10 |
| reverse 空结果 | 纯空行输入；参数 `--reverse` | stdout 零字节；退出 0 | C03、C06、C07 |
| 非法 UTF-8 | 原始字节 `62 0A FF`，即合法 `b` 行后接非法字节 | stdout 零字节；退出 2；stderr 有原因 | C01、C10，尤其验证整次调用的输出原子性 |
| 未知选项 | 合法输入；参数 `--unknown` | stdout 零字节；退出 2；stderr 有原因 | C08 |
| 路径参数 | 合法输入；参数 `input.txt` | stdout 零字节；退出 2；stderr 有原因，不作为路径读取 | C08 |

实现验收须覆盖以上案例（C10），并通过实际命令入口核对标准流行为。
