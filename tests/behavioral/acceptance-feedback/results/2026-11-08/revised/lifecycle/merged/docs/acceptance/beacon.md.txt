# Beacon acceptance

统一维护 import 和 export 的当前验收结论、证据与有效反馈。

## Import

[当前要求](../specs/import.md)。当前只验收了非空 ASCII 示例；Unicode、空输入与原子失败未完成验收，见[现有检查](../../evidence/import.txt)。

客户反馈：请修复非法行产生部分状态的问题，仍有效；实现差距尚未解决，仍影响非法行必须整次失败且不产生部分状态的接受要求。

import-fix 的目标原为修复部分状态写入并验证导入原子性，未完成即由客户明确取消，不再恢复。取消不撤销现行接受要求，也不关闭上述反馈或补足缺失验收。未来是否实施尚未决定；这里保留待决定事项，不安排新开发或验收。

## Export

[当前要求](../specs/export.md) 的 event_id code-point 升序、UTF-8 编码、逐事件 LF 换行及空输出零字节均已通过所列验收，见[结果](../../evidence/export.txt)。当前没有有效未处理反馈。
