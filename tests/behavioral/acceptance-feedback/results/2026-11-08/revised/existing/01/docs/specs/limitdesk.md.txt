# LimitDesk contract
parse_limit 的 None 默认返回整数 30；仅接受 5..120（含）的 Python int，bool 不算 int。其他类型或越界值抛 ValueError，不做隐式字符串/浮点转换；异常不返回部分结果。函数无文件或网络 I/O，不修改输入或外部状态，实现无第三方依赖。验收覆盖 None、5、120、4、121、True、"30"、30.0；当前没有性能目标。未来客户建议须另行确认后才能成为接受要求。

当前实现符合上述接受要求；已有功能测试通过，代码核对确认无 I/O、输入或外部状态修改及第三方依赖。当前验收范围、证据及有效反馈由[既有验收记录](../../quality/current.md)维护。
