# APEX structural contract tests

The runner executes the compact series and documentation ownership checks. It
verifies the seven-skill inventory, frontmatter/directory consistency, bootstrap
imports, migration documentation, Git/subagent boundaries, documentation
topology, and evidence-freshness wording.

Run all tests:

```bash
./run-skill-tests.sh
```

Run one test:

```bash
./run-skill-tests.sh --test ../apex/test-series-contract.sh
```

These are structural checks. Behavior and routing comparisons live under
`evals/` and in the sibling `apex-workspace/` generated by skill-creator.
