# Sentinel score-method v2

本文件承接方法要求 M01–M18 及已接受的 v2 变更，持续维护检测器与设备 SDK 共同消费的当前方法契约。实现优化必须保持本契约；方法接受或替换与 QA 的 evaluation protocol v3 独立进行。本文规定要求，不表示已有实现或符合性证据。

## 输入、输出与流状态

- **M01**：输入为 `(stream_id, event_id, timestamp, x)`，`x` 为有限实数。成功输出包含 `stream_id`、`event_id`、`score`、`anomaly`、`warmup_remaining`，不得省略 warmup 状态。
- **M02**：每条流独立维护最近 `W=128` 个已接受值；均值、窗口、去重状态均不得跨流共享。
- **M08**：同一流的 timestamp 不得小于上一条已接受输入的时间，相同 timestamp 允许。逆序新输入返回 `OUT_OF_ORDER`，不改变窗口、去重状态或最后时间。
- **M09**：NaN、正无穷、负无穷返回 `INVALID_VALUE`，不改变任何状态，也不消耗 warmup。
- **M10**：同流已保留的 event_id，若 timestamp 与数值均相同，返回该事件原始输出，不再次插入窗口；若 timestamp 或数值不同，返回 `EVENT_CONFLICT`，不改状态。原始输出包括原事件当时的 warmup 状态，不能按当前窗口重新计算。
- **M11**：去重保留最近 128 个已接受 event_id，按 FIFO 淘汰；重放不刷新 FIFO。淘汰后的 id 按普通新事件处理，并接受时间检查，不再保证重放原输出。
- **M12**：批输入按数组顺序逐条处理，不预排序；单条错误不回滚其他条的成功更新。不得先更新整个批次窗口再打分。
- **M13**：`reset(stream_id)` 清空指定流的窗口、最后时间与去重状态，不影响其他流。

已保留事件的相同内容重放按 M10 返回原输出；不能因为它早于随后已接受事件而将该重放改为逆序新输入。多个错误条件同时成立时的优先级尚未定义，不能凭实现顺序建立额外契约。

## 打分与窗口更新

**M03**：以下 `n`、均值、标准差均取插入当前 `x` 之前的窗口。先算输出，再插入本次有效且被接受的 `x`；超过 128 个值时移除最旧值。异常值仍是有效输入，照常进入窗口。

**M04**：当 `n<32`，`score=null`、`anomaly=false`、`warmup_remaining=32-n`，本次输入仍插入窗口。当 `n>=32`，`warmup_remaining=0`。

**M05–M07**：当 `n>=32`：

```text
mu    = sum(v for v in prior_window) / n
sigma = sqrt(sum((v - mu)^2 for v in prior_window) / n)
score = abs(x - mu) / max(sigma, 0.001)
anomaly = (score > 3)
```

标准差使用总体分母 `n`，不得使用 `n-1`。分母是 `max(sigma, 0.001)`，不得将 epsilon 加到 sigma，也不得在求标准差前作与此不同的方差截断。`score=3` 时不算异常。

**M15**：单条有效输入的数值输出绝对误差不得超过 `1e-9`；不得通过近似方差改变异常布尔值。内部计算与优化方案可选择，但必须保持上述方法语义。

## 保存与恢复

**M14**：保存与恢复必须保留窗口顺序、最后时间、去重 FIFO 与各事件原始输出。恢复后的继续输入结果须与不中断执行一致。快照格式尚未选定；本契约只规定必须保留的状态与连续性，不指定序列化方案。

## 方法验收

| 要求 | 必须检验的行为 |
|---|---|
| M16，向量 A | 先接受依次交替的 32 个 `-1,+1`，当前 `x=3`：`mu=0`、`sigma=1`、`score=3`、`anomaly=false`；当前 x 不得提前进入均值。 |
| M17，向量 B | 先接受 32 个 `0`，当前 `x=0.004`：`score=4`、`anomaly=true`；sigma 为零不能导致 null 或无穷输出。 |
| M18，warmup | 从空状态输入：第 32 次输入使用 `n=31`，输出 null/false/1；第 33 次使用 `n=32`，开始打分且 warmup_remaining 为 0。 |
| M18，窗口 | 覆盖第 128/129 个值的边界，确认第 129 次打分使用此前 128 个值，随后才移除最旧值。 |
| M18，重放与淘汰 | 覆盖原始输出重放、重放不刷新 FIFO、128/129 个唯一已接受 id 的淘汰边界及淘汰后的时间检查。 |
| M18，隔离与错误 | 覆盖多流隔离、单流 reset、逆序/无效值/冲突错误不变状态、批次部分成功及顺序处理。 |
| M14、M18，连续性 | 将含窗口、最后时间、FIFO 与原始输出的状态保存后恢复，后续普通输入、重放、冲突、淘汰的结果与不中断执行一致。 |

上述边界和向量不能替代 M01–M15 的完整契约符合性检查。设备 SDK 方法兼容性独立验收，不因 QA 评测器通过而视为完成。
