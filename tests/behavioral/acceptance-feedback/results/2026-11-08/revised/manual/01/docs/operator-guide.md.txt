# 本地任务运行手册

本手册供值班同事离线使用，依据项目的 `README.md` 和 `--help.txt` 编写。运行器不访问网络，无第三方依赖。以下命令在包含 `runner.py` 的项目目录执行。

## 选择参数

可先查看随项目提供的 `--help.txt`，也可运行：

```text
python runner.py --help
```

`-h` 与 `--help` 均显示帮助并以退出码 0 结束。

| 参数 | 选择要求 |
| --- | --- |
| `--input PATH` | 指向已存在的 UTF-8 JSON Lines 文件。 |
| `--output PATH` | 指向新的输出文件；已有文件会被拒绝，不能覆盖。 |

JSON Lines 输入应逐行包含 JSON 数据。选择输出路径时使用尚不存在的文件名；如需重跑，另选新的输出文件名。

## 运行本地任务

将示例路径替换为本次任务的实际路径。路径含空格时保留引号。

```text
python runner.py --input "data/input.jsonl" --output "data/result.jsonl"
```

运行结束后查看退出码，并确认本次指定的输出文件。不要仅凭目录中有同名或旧结果文件判断本次成功。

## 出错时查看什么

| 退出码 | 含义与检查项 |
| --- | --- |
| `0` | 成功；如使用了帮助参数，则表示帮助已正常显示。 |
| `2` | 参数或输入格式错误。查看标准错误输出（stderr）中的具体原因。 |

遇到错误，先查看终端中的 stderr 信息，再对照实际命令检查：输入路径是否指向已有文件、输入是否为 UTF-8 JSON Lines、输出文件是否已经存在，以及参数是否与帮助文本一致。修正后使用新的输出文件路径重跑。

需要保留错误信息供离线排查时，可将 stderr 保存到本地日志，例如：

```text
python runner.py --input "data/input.jsonl" --output "data/result.jsonl" 2> "runner-error.log"
```

上述命令会写入或覆盖 `runner-error.log`，需要保留旧日志时请另选文件名。日志是错误诊断信息，不是任务输出。

运行失败不会产生输出文件。若原因仍不清楚，保留实际运行命令、退出码和完整 stderr，作为继续排查的依据。
