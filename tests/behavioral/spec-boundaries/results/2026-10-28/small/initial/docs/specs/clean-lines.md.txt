# clean-lines 规范

本文件维护所有者已接受的 clean-lines 当前契约，包括命令行接口、文本处理语义和验收要求。`tmp/requirements.md` 是传入基线，后续契约维护由本文件承担。

clean-lines 供本地编辑器调用，作为单一工具整体发布和验收。内部读取、过滤、排序、写出步骤属于这一契约，不形成独立接口或兼容性承诺。

## 接口与处理语义

| 要求 | 契约 |
| --- | --- |
| C01 | 从 stdin 读取严格 UTF-8。遇到非法 UTF-8 时退出 2，在 stderr 给出简短原因，stdout 必须为空，包括非法字节之前已有合法内容的情况。 |
| C02 | 接受 LF 和 CRLF 行分隔。每行仅去除行终止符，不去除内容中的空格。 |
| C03 | 仅删除长度为零的行；仅含空格的行保留。 |
| C04 | 按字符串完全相等去重，区分大小写，不做 Unicode 规范化。 |
| C05 | 按 Unicode code point 升序排序，不使用 locale 排序。 |
| C06 | 输出 UTF-8，以 LF 换行，每个保留行末尾恰好追加一个 LF。空输入或过滤后为空时输出零字节。 |
| C07 | 可选参数 `--reverse` 仅反转最终排序结果，不改变去重和空行定义。 |
| C08 | 成功退出 0；未知参数退出 2，在 stderr 提示，stdout 为空。不接受文件路径参数，不原地修改文件。 |

语言、依赖和内部组织不属于已接受行为约束。实现必须保证错误时的 stdout 原子性；具体缓冲或验证方式由实现选择。

## 验收

C09 的示例及 C10 的覆盖要求如下。表中 `\n`、`\r` 是字符表示，`\xFF` 表示单个非法 UTF-8 字节，`空` 表示零字节；双引号用于界定内容，不属于输入输出。

| 场景 | 参数 | stdin | 预期 stdout | 退出码 | 对应要求 |
| --- | --- | --- | --- | --- | --- |
| 接受示例 | 无 | `"b\n\nA\nb\n \n"` | `" \nA\nb\n"` | 0 | C02–C06、C09 |
| CRLF 输入 | 无 | `"b\r\n\r\nA\r\nb\r\n \r\n"` | `" \nA\nb\n"` | 0 | C02、C06、C09 |
| 空输入 | 无 | 空 | 空 | 0 | C06、C10 |
| 纯空行 | 无 | `"\n\r\n\n"` | 空 | 0 | C02、C03、C06、C10 |
| 重复与大小写 | 无 | `"b\nA\na\nA\n"` | `"A\na\nb\n"` | 0 | C04、C05、C10 |
| 内容空格保留 | 无 | `"a \n a\n \na \n"` | `" \n a\na \n"` | 0 | C02–C05、C10 |
| 非 ASCII 与规范化 | 无 | 依次为 U+00E9 的行、U+0065 U+0301 的行、U+00E9 的行，均以 LF 结束 | U+0065 U+0301 的行，然后 U+00E9 的行，均以 LF 结束 | 0 | C04、C05、C06、C10 |
| 完整 code point 排序 | 无 | U+1F600 的行，然后 U+E000 的行，均以 LF 结束 | U+E000 的行，然后 U+1F600 的行，均以 LF 结束 | 0 | C05、C10 |
| 反向结果 | `--reverse` | `"b\n\nA\nb\n \n"` | `"b\nA\n \n"` | 0 | C03、C04、C07、C10 |
| 非法 UTF-8 与原子性 | 无 | `"A\n"` 后接字节 `\xFF` | 空；stderr 给出简短原因 | 2 | C01、C10 |
| 未知参数 | `--unknown` | `"A\n"` | 空；stderr 提示 | 2 | C08 |
| 文件路径参数 | `input.txt` | `"A\n"` | 空；stderr 提示 | 2 | C08 |

验收需同时检查输出字节和进程退出码；失败用例还需检查 stderr 有对应原因。示例并不替代 C01–C08 的一般规则。
