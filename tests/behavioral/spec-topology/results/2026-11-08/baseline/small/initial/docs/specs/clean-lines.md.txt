# clean-lines 规范

## 用途与范围

clean-lines 是供本地编辑器调用的命令行工具，从 stdin 接收文本，在 stdout 返回去除空行、去重并排序的文本。只有一个消费者，整体发布和验收；内部读取、过滤、排序、写出步骤不拥有独立接口或兼容性承诺。

本文维护所有者已接受的 C01–C10 合同。传入要求已吸收为下述规范，后续合同变更在本文维护。语言、依赖和内部结构未指定，不构成对实现者的限制。

## 命令行与数据合同

调用形式为 `clean-lines` 或 `clean-lines --reverse`。输入仅来自 stdin，输出仅写 stdout；诊断写 stderr。没有文件路径参数，也没有原地修改文件功能。

| 要求 | 规范行为 |
|---|---|
| C01 | 严格按 UTF-8 解码 stdin。任何非法 UTF-8 都使进程退出 2，stderr 给出简短原因，stdout 为零字节；即使错误出现在有效内容之后也必须如此。 |
| C02 | 接受 LF 与 CRLF 行分隔。每行只去除行终止符，不 strip 空格。 |
| C03 | 仅删除长度为零的行；一个或多个空格组成的行必须保留。 |
| C04 | 按字符串完全相等去重，区分大小写，不做 Unicode 规范化。 |
| C05 | 按 Unicode code point 升序对字符串作字典序排序，不使用 locale 排序。逐个码点比较，首个不同码点决定先后；一方为另一方前缀时，较短者在前。 |
| C06 | 输出编码为 UTF-8，行终止符为 LF；每个保留行后恰有一个 LF。空输入或过滤后为空时输出零字节。 |
| C07 | `--reverse` 仅反转最终排序结果，去重规则和空行定义不变。 |
| C08 | 成功退出 0。未知参数退出 2，stderr 提示，stdout 为零字节。文件路径也不属于支持的参数。 |

非法输入与未知参数的 stdout 原子性是对外要求：不得先输出可见的部分结果，再因错误退出。实现可以选择适合的缓冲方式，规范不要求特定算法或存储结构。

## 验收

下表是应由后续实现者执行的验收用例，尚无运行证据。除明确写出退出 2 的情况外，均应退出 0。字符串采用转义表示，`\n` 为 LF、`\r\n` 为 CRLF，`" "` 是单个 U+0020；字节序列用十六进制表示。

| 用例 | stdin / 参数 | 预期 stdout 与其他断言 | 覆盖 |
|---|---|---|---|
| 基本组合 | `"b\n\nA\nb\n \n"` | `" \nA\nb\n"` | C02、C03、C04、C05、C06、C09 |
| CRLF | `"b\r\n\r\nA\r\nb\r\n \r\n"` | `" \nA\nb\n"`，不含 CRLF | C02、C06、C09 |
| 空输入 | 零字节 | 零字节 | C06、C10 |
| 纯空行 | `"\n\r\n\n"` | 零字节 | C02、C03、C06、C10 |
| 重复与大小写 | `"a\nA\na\nA\n"` | `"A\na\n"` | C04、C05、C10 |
| 保留空格 | `"a \n a\n \n  \na \n"` | `" \n  \n a\na \n"` | C02、C03、C04、C05、C10 |
| 非 ASCII 与规范化 | `"\u00E9\ne\u0301\n\u00E9\n"` | `"e\u0301\n\u00E9\n"`，两种字符串均保留 | C01、C04、C05、C06、C10 |
| 码点顺序 | `"\U00010000\n\uE000\n"` | `"\uE000\n\U00010000\n"`，防止误用 UTF-16 code unit 顺序 | C05、C10 |
| 前缀 | `"aa\na\n"` | `"a\naa\n"` | C05 |
| reverse | 基本组合输入，参数 `--reverse` | `"b\nA\n \n"` | C07、C10 |
| reverse 空结果 | 纯空行输入，参数 `--reverse` | 零字节 | C03、C06、C07 |
| 非法 UTF-8 | 字节 `FF`；另测 `61 0A FF` 和截断序列 `61 0A E4 B8` | 每次均退出 2，stderr 有简短原因，stdout 为零字节 | C01、C10 |
| 未知参数 | 有效文本，参数 `--unknown`；另测参数 `input.txt` | 每次均退出 2，stderr 有提示，stdout 为零字节 | C08 |

C10 要求的空输入、纯空行、重复行、非 ASCII、带空格行、reverse 和非法输入 stdout 原子性均需实际验收；文档检查不能代替这些运行检查。诊断消息的具体措辞没有被指定，不应以固定文本匹配限制实现。
