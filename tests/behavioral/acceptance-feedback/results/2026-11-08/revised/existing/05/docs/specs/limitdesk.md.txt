# LimitDesk contract
parse_limit 的 None 默认返回整数 30；精确字符串 "auto" 也返回整数 30，区分大小写且不去除空白，"Auto" 和带空格形式须抛 ValueError。其余显式值仅接受 5..120（含）的 Python int，bool 不算 int。其他类型、其他字符串或越界值抛 ValueError，不做隐式字符串/浮点转换；异常不返回部分结果。函数无文件或网络 I/O，不修改输入或外部状态，实现无第三方依赖。

功能验收覆盖 None、5、120、4、121、True、"30"、30.0，以及 "auto"、"Auto" 和带空格形式（含前置、后置空格）。
