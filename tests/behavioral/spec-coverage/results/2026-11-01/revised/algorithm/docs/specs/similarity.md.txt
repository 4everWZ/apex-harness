# Mosaic 特征与精确查询规范

本文拥有 F01–F08 和 Q02–Q10 的算法语义与验收细节。输入合法性、原像素使用、串行状态及持久性由整体工具规范拥有；本文所有图片运算均使用该输入契约。技术层属于 Mosaic 整体契约，不单独发布。

## 特征定义

给定接受的 H×W×3 RGB 矩阵，坐标从 0 起算。

1. **F01：**每个像素的亮度为 `L=(299R+587G+114B)/1000`，不舍入为整数，不做 gamma 修正。
2. **F02：**8×8 网格覆盖原矩阵。网格行 i 对应半开区间 `[floor(i×H/8), floor((i+1)×H/8))`，网格列 j 对应 `[floor(j×W/8), floor((j+1)×W/8))`；i、j 均为 0–7。分区均值不能替换成均匀取样点。
3. **F03：**`m[i,j]` 为该区域全部像素亮度的算术平均。`mbar=(Σ_i Σ_j m[i,j])/64`，即 64 个单元等权；不是对原图所有像素直接求均值。
4. **F04：**`b[i,j]=1` 当且仅当 `m[i,j] >= mbar`，否则为 0。按行优先将 `(i,j)` 映射到 bit `8i+j`，即 `(0,0)` 为 bit 0、`(7,7)` 为 bit 63；不得因字节端序反转位序。
5. **F05：**颜色向量 `c=(cR,cG,cB)`，其中每个分量为对应 RGB 通道全部 H×W 个像素的均值除以 255，范围为 `[0,1]`。
6. **F06：**特征为 `(64 位 b,c)`。保存与恢复保留足以按同样规则比较的值，误差不大于 `1e-12`；不能用会改变排序的低精度压缩格式。

## 特征验收向量

- **F07：**任意常量色、尺寸合法的图片，64 位均为 1，等于均值不能产生全零。8×8 图片只有左上角为白色、其余为黑色时，仅 bit 0 为 1。
- **F08：**覆盖 9×17 等不能整除的尺寸，检查 floor 分区边界和 64 单元等权。对 9×17，行边界依次为 `0,1,2,3,4,5,6,7,9`，列边界为 `0,2,4,6,8,10,12,14,17`；最后一行和最后一列区域较大，计算 mbar 时仍与其他单元等权。不得用库默认缩放到 8×8 代替分区及均值定义。

向量验收必须检查亮度、单元均值、全局单元均值、位序和颜色向量，避免最终位串偶然相同掩盖计算差异。

## 查询接口语义

**Q02：**查询输入可以是已经解码的图片或索引内 `image_id`。图片遵循相同输入和特征规则；id 不存在返回 `NOT_FOUND`。查询不得向索引添加内容。

设候选特征为 `(b,c)`、查询特征为 `(q_b,q)`：

- **Q03：**`h=popcount(b XOR q_b)`，为 0–64 的整数；归一化 Hamming 距离 `h'=h/64`。
- **Q04：**`d=(abs(cR-qR)+abs(cG-qG)+abs(cB-qB))/3`，总距离 `D=0.75×h'+0.25×d`。不得改为欧氏距离，也不得先舍入两个分量。
- **Q05：**`max_distance` 必须为 `[0,1]` 内有限数，非法返回 `INVALID_THRESHOLD`。候选保留条件为 `D <= max_distance`，相等时包含。
- **Q06：**`k` 必须为 1–100 的整数，非法返回 `INVALID_K`。不足 k 项时全部返回，空索引返回空数组。
- **Q07：**先按 D 升序；D 相等时按 `image_id` 的 Unicode code point 升序稳定决胜，不得用插入顺序、locale 或显示文件名破平局。
- **Q08：**以索引内 id 查询时，仅排除该 id 自身；其他不同 id 即使像素完全相同仍可返回。图片查询不做隐式自排除。
- **Q09：**每项返回 `image_id`、D、原始整数 h、颜色距离 d。显示值可单独格式化，但排序和门限判断使用未舍入数值。
- **Q10：**初版结果必须与全量精确扫描相同。内部结构可另选，但未经接受不得采用近似检索、提早截断或丢弃候选来提升性能。

因此查询的可观察结果应相当于：取得查询特征，确定允许候选，计算全部相关距离，按门限保留，按 `(D, image_id code points)` 排序后取前 k 项。该语义不强制具体数据结构或编程接口。

## 查询验收

分别使用已知特征验证 XOR/popcount、h/64、L1 颜色距离与加权公式；覆盖零距离及最大距离、非法门限（包括非有限数）、k 两端及非法值、门限边界、结果不足 k 和空索引。检查同距离不同 id 的 Unicode 排序，以及 id 查询和图片查询的自排除差异。用全量精确扫描语义比对任一内部索引结构的完整返回项与次序；不能只比较数量或近似命中率。
