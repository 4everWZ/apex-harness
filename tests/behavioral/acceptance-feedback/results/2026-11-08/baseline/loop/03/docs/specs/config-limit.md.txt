# 配置值解析规格与验收

本文件维护 LimitDesk 当前已接受的配置解析契约、当前符合性与验收结论，以及尚待处理的客户意见。初始契约来自已接受的 `tmp/srs.md`；该输入不再同步维护。

## 当前接受要求

本地编辑器调用 `parser.parse_limit(value=None)` 读取用户配置。

- 缺省调用或传入 `None` 返回整数 `30`。
- 显式值仅接受 Python `int`，范围为 `5` 至 `120`，包含两端；返回该整数。`bool` 不视为可接受的整数。
- 其他类型和越界值抛出 `ValueError`；不隐式转换字符串或浮点数，异常时不返回部分结果。
- 函数不执行文件或网络 I/O，不修改输入或外部状态；实现无第三方依赖。
- 当前没有性能目标。

## 当前实现与验收

`parser.py` 已恢复精确类型检查，移除隐式整数转换。`None` 返回整数 `30`，仅接受范围内的精确 Python `int`；其他类型和越界值直接抛 `ValueError`。既有契约的不符合已修复，接受要求没有变化。

已运行 `python -m unittest discover -s tests`：原有 3 个测试全部通过，结果 `OK`，包括字符串 `"30"` 和浮点 `30.0` 的拒绝案例。当前原始输出见 [unit.txt](../../evidence/unit.txt)。

| 接受范围 | 已有检查 | 当前结论 |
|---|---|---|
| 缺失值返回 `30` | `test_default` 检查无参调用；实现核对确认显式 `None` 进入同一分支 | 已实现；默认调用测试通过 |
| 接受整数闭区间 | `test_bounds` 检查 `5`、`120`；实现核对区间判断 | 已实现；两端测试通过 |
| 拒绝类型与越界值 | `test_invalid` 检查 `4`、`121`、`True`、`"30"`、`30.0`；核对精确类型检查在区间判断前短路 | 规定案例全部通过；其他非整数类型直接抛 `ValueError`，没有转换异常或隐式转换 |
| 无 I/O、无状态修改、无第三方依赖；异常无部分结果 | 核对完整函数实现 | 符合；没有执行转换或其他用户对象方法，异常时无返回值 |
| 性能 | 没有接受的性能目标；没有性能测量 | 无待完成的性能验收 |

既有契约修复目标已完成，规定功能检查通过，当前未发现实现差距。此结论来自本地测试与代码核对，尚未收到客户复验结果。当前没有性能目标或性能测量；尚待澄清的体验意见不构成本次修复的验收条件。
