# Mosaic 索引与检索规范

本规范负责已接受的 Q01–Q10。图片查询使用与添加相同的输入规则，并按[特征规范](features.md)计算特征。

## 索引记录与查询入口

**Q01：**索引保存 `image_id`、特征及用于判定同 id 输入是否像素完全相同的内容身份。原始图片不持久化到索引。身份表示方式尚未选择，但不能降低像素完全相同的判定要求。

**Q02：**查询可传已解码图片或索引内 `image_id`。图片按相同输入与特征规则处理；id 不存在返回 `NOT_FOUND`。查询不向索引添加内容。

**Q08：**按索引内 id 查询时，只排除该 id 自身；其他像素相同的不同 id 仍可返回。图片查询不隐式排除任何自身候选。

## 距离

设候选位特征为 b、颜色为 c，查询位特征为 qb、颜色为 q。

- **Q03：**`h = popcount(b XOR qb)`，即异或结果中 1 的数量，是 0–64 的原始整数；`h' = h/64`。
- **Q04：**`d = (abs(cR-qR) + abs(cG-qG) + abs(cB-qB))/3`；`D = 0.75×h' + 0.25×d`。不能改成欧氏距离，也不能先将两个分量舍入。

## 候选、排序与结果

| 编号 | 接受契约 |
|---|---|
| Q05 | `max_distance` 必须为 [0,1] 内有限数，否则返回 `INVALID_THRESHOLD`。仅保留 `D <= max_distance` 的候选，包含相等边界。 |
| Q06 | k 必须为 1–100 的整数，否则返回 `INVALID_K`。有效查询不足 k 项时全部返回；空索引返回空数组。 |
| Q07 | 按 D 升序；D 相等时按 `image_id` 的 Unicode code point 升序稳定决胜。不能使用插入顺序、locale 或显示文件名破平局。 |
| Q09 | 每项返回 `image_id`、D、原始整数 h 和颜色距离 d。显示值可单独格式化；排序和门限判断必须使用未舍入数值。 |
| Q10 | 初版返回结果必须与全量精确扫描相同。内部索引结构可另选，但未经接受，不得使用近似检索、提早截断或丢弃候选来提升性能。 |

## 独立验收

| 范围 | 检查 |
|---|---|
| Q01–Q02 | 检查保存内容不持久化原图；同 id 同像素重放与不同像素冲突仍可判定。比较图片与对应索引 id 查询的结果，验证图片查询不添加记录及未知 id 返回 `NOT_FOUND`。 |
| Q03–Q04 | 独立构造位特征和颜色向量：同特征应得到 h=0、d=0、D=0；位全异且对应颜色分量差均为 1 时应得到 h=64、d=1、D=1；加入部分位差与混合颜色差以区分规定权重、L1 颜色距离和舍入错误。 |
| Q05–Q06 | 检查阈值 0、1、恰等于 D、刚低于 D，以及非有限数和越界；检查 k=1、100、0、101、非整数、不足 k 项和空索引。 |
| Q07 | 用相同 D、不同 id 的候选，以独立 code point 序列比较核对顺序；包含大小写、非 ASCII 和补充平面字符，并改变插入顺序以识别错误决胜方式。 |
| Q08–Q09 | 相同像素不同 id，核对 id 查询仅排除自己、图片查询无隐式自排除，以及所有返回字段。用显示后相同但原值不同的距离核对门限与排序仍使用原值。 |
| Q10 | 以独立全量精确扫描作为参照，比较候选集合、结果顺序、截取 k 后结果和距离字段；覆盖边界、平局、删除与恢复后的状态。任何优化必须保持精确结果。 |
