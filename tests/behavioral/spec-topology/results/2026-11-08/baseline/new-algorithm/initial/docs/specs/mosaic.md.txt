# Mosaic 整体规范

本规范承接所有者已接受的要求；契约已接受，实现尚未开始。`tmp/requirements.md` 是一次性输入，不再承担持续维护职责。本文件维护工具范围、输入、索引状态、持久性与整体验收；[特征与检索规范](mosaic-retrieval.md) 维护内部算法及其独立验收。两层属于同一个工具契约，整体发布、整体验收，没有独立 SDK 或模块兼容发布。

## 范围与运行条件

Mosaic 是本地主机上的重复图片检索工具。输入由调用者解码为像素矩阵；图片格式解码、网络服务与 GUI 不在范围内。添加、删除、查询按调用顺序串行执行，没有并发写承诺（I05）。语言、依赖、索引结构、输入内容身份表示及快照格式均未选择；以下定义行为，不指定这些实现。

## 输入与状态

| 要求 | 接受的行为 |
|---|---|
| I01 | 图片必须是非空 H×W×3 整数 RGB 矩阵，通道值为 0–255。非法维度、非整数或越界值返回 `INVALID_IMAGE`，索引状态不变。 |
| I02 | H 或 W 小于 8 返回 `IMAGE_TOO_SMALL`。不得复制像素或插值来悄悄放大输入。 |
| I03 | 每张图片使用区分大小写的 UTF-8 `image_id`。同 id、完全相同像素的重复添加返回原确认，不重建特征；同 id、不同像素返回 `ID_CONFLICT`，状态不变。 |
| I04 | 特征与确认只从成功接受的原像素派生。不得自动旋转、裁剪或做 EXIF 修正；调用者给出的行列顺序就是输入顺序。 |
| I06 | 单图添加失败不留下部分特征或 id。批添加按数组顺序逐项执行，单项失败不回滚其他成功项。 |
| I07 | 删除不存在的 id 为幂等成功；删除存在 id 后不得返回其旧特征。删除后可以重新添加该 id，按新图片处理。 |
| I08 | 不得修改调用者矩阵，也不得让调用者在输入返回后的变更改变已接受的索引内容。 |

索引保存 `image_id`、有效特征以及用于判定 I03 的输入内容身份，不持久化原始图片（Q01）。内容身份的实现尚未决定，但不得降低“像素完全相同”的判定要求。

查询接受已解码图片或索引内 `image_id`（Q02）。图片使用同一输入规则和特征算法；id 不存在返回 `NOT_FOUND`。查询不得向索引添加内容。候选排除、距离、筛选、排序及返回字段由特征与检索规范定义。

## 持久性

保存必须包含所有 id、有效特征与输入内容身份（A01）。恢复后，添加重放、冲突、删除与查询的行为须与不中断执行一致，不能仅恢复查询结果。特征数值精度要求由算法规范 F06 定义。

## 整体验收

下表描述必须建立的证据，不表示已有测试或测量。

| 要求 | 验收方式与预期 |
|---|---|
| I01–I02 | 分别覆盖空矩阵、非法维度、非整数、越界通道，以及任一维小于 8；检查相应错误、状态不变及未暗中放大输入。 |
| I03–I04 | 对同 id 同像素重放检查原确认与特征未重建；对同 id 不同像素检查冲突与状态不变。用有方向的像素矩阵检查未旋转、裁剪或按元数据修正。 |
| I05–I06 | 按串行调用观察状态；批中穿插成功项与失败项，确认顺序逐项执行、失败无部分状态且其他成功项保留。 |
| I07–I08 | 删除不存在 id、删除后查询、删除重加；比较调用前后矩阵，并在添加返回后修改调用者矩阵，检查索引保持原接受内容。 |
| Q01–Q02 | 检查持久化内容未含原图且身份足以完成重放/冲突判定；对图片查询与 id 查询分别验证输入行为、缺失 id 及查询无新增状态。 |
| F01–F08、Q03–Q10 | 依算法规范进行独立特征和距离向量验收，并与全量精确扫描结果比较。 |
| A01–A02 | 执行同像素不同 id、添加后修改调用者矩阵、删除重加、同距离平局、门限恰好相等、k 大于现有数量、恢复后重放等组合场景。对同一操作序列比较不中断执行与保存/恢复执行的确认、错误、状态及结果；须包括恢复后冲突、删除和查询。 |

### 性能条件（A03–A05）

固定主机 H1、10000 张已建索引图片、单线程、k=10，查询延迟 p95 必须不超过 50ms。计时包含查询特征与距离排序，不包含图片加载和索引保存。

p95 使用 nearest rank：将 N 个样本升序排列，取第 `ceil(0.95*N)` 个，位置从 1 开始。无样本报告 `unavailable`，不得报告 0。

未经测量不得宣称性能达标。不同主机、图片集、解码条件或近似检索配置的结果不得当作同条件提升。每次参数与原始实验结果由运行输出持有，不堆入规范。当前没有可引用的实现或性能证据（A06）；H1 的具体配置、图片集及采样方案仍需在执行前明确。
