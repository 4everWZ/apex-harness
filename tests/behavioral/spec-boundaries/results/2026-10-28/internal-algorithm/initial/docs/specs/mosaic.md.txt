# Mosaic 工具规范

本文件是 Mosaic 已接受契约的维护入口，承接项目所有者接受的 I01–I08、F01–F08、Q01–Q10、A01–A06。要求已接受，实现与符合性尚未验证。输入处理、特征、索引和查询共同构成本工具的一个契约，不独立发布或验收。

## 范围

Mosaic 只在本地主机运行，接收调用者已经解码的像素矩阵。不包含图片格式解码、网络服务或 GUI。特征、索引和检索只供工具内部使用，不提供外部 SDK，不承诺模块版本兼容发布，也没有分开的团队维护边界。工具整体发布、整体验收。

## 输入与状态变化

- **I01**：图片为非空 H×W×3 的整数 RGB 矩阵，各通道值为 0–255。非法维度、非整数或越界值返回 `INVALID_IMAGE`，索引状态不变。
- **I02**：H 或 W 小于 8 返回 `IMAGE_TOO_SMALL`；不得通过复制像素或插值悄悄放大输入。
- **I03**：每张图片具有区分大小写的 UTF-8 `image_id`。同 id、像素完全相同的重复添加返回原确认，不重建特征；同 id、不同像素返回 `ID_CONFLICT`，状态不变。
- **I04**：特征与确认只从成功接受的原像素派生。不得自动旋转、裁剪或进行 EXIF 修正；矩阵行列顺序由调用者给出。
- **I05**：添加、删除和查询按调用顺序串行执行；当前没有并发写承诺。
- **I06**：单图添加失败不留下部分特征或 id。批添加按数组顺序逐项执行；单项失败不回滚其他成功项。
- **I07**：删除不存在的 id 为幂等成功。删除存在的 id 后不得再返回其旧特征；删除后可重新添加该 id，并按新图片处理。
- **I08**：不得修改调用者的像素矩阵，也不得在输入返回后借其后续变更改变已接受的索引内容。

## 内部特征规则

- **F01**：逐像素计算亮度 `L=(299R+587G+114B)/1000`，不舍入为整数、不做 gamma 修正。
- **F02**：8×8 网格覆盖原矩阵。网格行 i 对应半开区间 `[floor(i*H/8), floor((i+1)*H/8))`，列 j 对应 `[floor(j*W/8), floor((j+1)*W/8))`，i、j 均为 0–7。不得用均匀取样点代替分区均值。
- **F03**：`m[i,j]` 是对应区域全部亮度的算术平均。`mbar` 是 64 个单元均值的算术平均，而非原图全部像素的均值。
- **F04**：当且仅当 `m[i,j]>=mbar` 时 `b[i,j]=1`。按行优先把 (0,0) 到 (7,7) 映射到 bit 0 到 bit 63，不得按字节端序反转位序。
- **F05**：RGB 各通道全图均值除以 255，得到 `c=(cR,cG,cB)`，每个分量位于 [0,1]。
- **F06**：特征是 `(64 位 b, c)`。保存与恢复须保留足以按相同规则比较的值，误差不大于 `1e-12`；不得压缩为会改变排序的低精度格式。
- **F07**：任意常量色图片的 64 位均为 1，不能因等于均值生成全零。8×8 图像仅左上像素为白、其余为黑时，仅 bit 0 为 1。
- **F08**：验收须覆盖 9×17 等非整除尺寸，检查 floor 分区与 64 单元等权；不得用缩放到 8×8 的库默认行为代替 F02–F03。

## 索引与查询

- **Q01**：原始图片不持久化到索引。索引保存 `image_id`、特征和用于判定 I03 的输入内容身份；身份表示方式未选，但不得降低像素完全相同的判定。
- **Q02**：查询接收已解码图片或索引内 `image_id`。图片使用相同输入与特征规则；id 不存在返回 `NOT_FOUND`。查询不向索引添加内容。
- **Q03**：Hamming 距离 h 为两个 64 位特征异或后的 1 位数，归一化距离 `h'=h/64`。
- **Q04**：颜色距离 `d=(abs(cR-qR)+abs(cG-qG)+abs(cB-qB))/3`，总距离 `D=0.75*h'+0.25*d`。不得改成欧氏距离，也不得先把两个分量舍入。
- **Q05**：仅保留 `D<=max_distance` 的候选，包含相等边界。`max_distance` 须为 [0,1] 内有限数，否则返回 `INVALID_THRESHOLD`。
- **Q06**：k 须为 1–100 的整数，否则返回 `INVALID_K`。不足 k 项时全部返回，空索引返回空数组。
- **Q07**：按 D 升序；D 相等时按 `image_id` 的 Unicode code point 升序稳定决胜。不得按插入顺序、locale 或显示文件名破平局。
- **Q08**：以索引内 id 查询时只排除该 id 自身；内容相同的其他 id 仍可返回。图片查询不做隐式自排除。
- **Q09**：每项返回 `image_id`、D、原始整数 h 和颜色距离 d。显示值可另行格式化，但排序与门限判断须使用未舍入值。
- **Q10**：初版结果须与全量精确扫描相同。内部索引结构可另选；未经接受不得使用近似检索、提早截断或通过丢候选提升性能。

## 持久性与验收

- **A01**：保存包含全部 id 及其有效特征、内容身份。恢复后，添加重放、冲突、删除和查询须与不中断执行一致，不能只恢复查询结果。
- **A02**：除输入、特征和查询距离的独立向量外，须组合验收：同像素不同 id、添加后修改调用者矩阵、删除重加、同距离平局、阈值恰好相等、k 超出现有数量、恢复后重放。
- **A03**：固定主机 H1，10000 张已建索引图片，单线程、k=10，查询 p95 须不超过 50ms。计时包含查询特征及距离排序，不包含加载图片或保存索引。
- **A04**：p95 使用 nearest rank：N 个样本升序后取第 `ceil(0.95*N)` 个，序号从 1 开始。无样本报告 `unavailable`，不得报告 0。
- **A05**：未测量不等于性能达标。不同主机、图片集、解码条件或近似检索配置的结果不得作为同条件提升。逐次参数和原始实验结果由运行输出持有，不堆入本规范。
- **A06**：语言、依赖、索引结构和快照格式尚未选择，不是所有者已接受的产品约束。当前没有可引用的实现或性能证据。

以上验收要求定义须达到的结果，不代表已完成验收。实现进度、待澄清事项与后续检查由当前工作计划维护。
