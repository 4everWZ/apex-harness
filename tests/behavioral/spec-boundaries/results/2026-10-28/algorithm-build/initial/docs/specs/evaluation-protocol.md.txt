# Sentinel evaluation protocol v3

本文件承接所有者已接受的 E01–E12，作为离线 QA 独立维护的评测规范。它与 SDK 的 score-method v1 独立接受、替换和验收；算法实现变更不自动改变该协议。协议已接受不表示评测器已实现或运行，也不表示目标已经达到。

- **E01** 标注集按流内时间顺序，每流按 60%/20%/20% 划分 train/validation/test，切点向下取整；不足样本的流计入排除数。
- **E02** train 可确定候选实现参数，validation 用于选型；test 只作最后一次对外比较，不依据 test 标签调整阈值或选变体。
- **E03** 各切分区间不共享检测器窗口或去重状态，各自从空状态开始。warmup 不计入质量指标，必须报告其排除数量。
- **E04** 质量指标为各流 F1 宏平均。无正例且无预测正例的流 F1=1；有正例但零命中时为 0。不得改为全体事件 micro F1。
- **E05** 标签按输出 event_id 对齐，不按批位置；重复事件输出按唯一 event_id 计一次。错误输入不计作负例。
- **E06** 延迟固定在主机 H1、单线程、batch=1 报告。计时包括 score 和窗口/去重更新，不包括加载、启动、快照写入和评测汇总。
- **E07** 延迟样本为 warmup 后有效唯一事件。p95 为排序后第 `ceil(0.95*N)` 个样本（1 起始），不线性插值；无样本为 unavailable，不能写 0。
- **E08** p95 目标 <=2 ms，质量不能劣于精确 v1 参考实现。目标不是已达到事实，必须由实际测量支持达成声明。
- **E09** 不同主机、线程、批大小、数据集、切分或 warmup 规则的结果，不能宣称为同条件算法提升。
- **E10** 报告包含各切分有效流数与事件数、排除原因、质量汇总及延迟样本量。逐样本原始结果由评测输出目录持有，不在规范积累运行日志。
- **E11** 评测器验收独立检查切分边界、泄漏防护、宏平均特殊值、标签对齐、warmup 排除、nearest-rank 分位数。检测器单元测试不能替代协议验收。
- **E12** SDK 方法兼容性与 QA 评测协议独立验收；算法改版不自动改协议 v3，最终还需验证检测器与评测器组合口径一致。

评测器执行前，须在不改变上述语义的前提下明确不足样本的可执行边界、标注数据接口及 H1 身份。该任务不提供这些额外信息，不能据此虚构真实评测结果。
